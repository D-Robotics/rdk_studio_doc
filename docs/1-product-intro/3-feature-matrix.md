# 1.3 功能入口

RDK Studio 的功能入口按左侧导航分为 **核心、开发工具、AI 能力** 三组。

可以先从工作台开始，再按任务进入烧录、远程桌面、代码编辑器、板端 Agent、本地大模型或技能工坊。

## 主导航

| 分组 | 入口 | 一句话职责 | 详见 |
|---|---|---|---|
| 核心 | 工作台 | Moss 对话与项目工作区，集中呈现设备状态、历史、诊断、变更、文件、终端 | [3.1](../3-user-guide/1-workbench/index.md) |
| 开发工具 | 烧录 | RDK X3 / X5 / S100 与其他本机镜像写入流程 | [3.7](../3-user-guide/7-system-flashing/index.md) |
| 开发工具 | 远程桌面 | 查看并操作板端图形界面 | [3.6](../3-user-guide/6-remote-desktop/index.md) |
| 开发工具 | 代码编辑器 | 打开板端代码编辑工作区 | [3.5](../3-user-guide/5-remote-ide/index.md) |
| AI 能力 | 板端 Agent | OpenClaw 部署、诊断修复、模型同步、板端对话 | [3.10](../3-user-guide/10-openclaw/index.md) |
| AI 能力 | 本地大模型 | 安装/启动 Ollama、下载模型、设为 Moss 快速模式 | [3.12](../3-user-guide/12-local-models/index.md) |
| AI 能力 | 技能工坊 | 本机 Moss 技能、设备 OpenClaw 技能、技能市场、从链接生成技能 | [3.11](../3-user-guide/11-skill/index.md) |

## 工作台里能做什么

工作台不是单一信息卡片，而是 Moss 的主要工作区。它包含这些常用内容：

| 内容 | 作用 |
|---|---|
| Moss 对话 | 发送自然语言任务，支持附件、设备信息、项目信息、执行/计划、快速/思考 |
| 当前状态 | 查看当前项目、设备、目录、Git 变更、诊断快照 |
| 历史 | 打开本地对话历史并继续之前的任务 |
| 诊断 | 采集设备运行时快照并送入 Moss |
| 变更 | 查看远端项目 Git 状态，必要时初始化工作区 |
| 文件 / 终端 / 浏览 | 在 Moss 旁边打开常用工具，减少来回切换 |

## 设置与资源入口

| 入口 | 内容 |
|---|---|
| 设置 | 账户与安全、设备连接、界面显示、AI 引擎、飞书、微信、应用与更新 |
| 资源与支持 | 地瓜开发者论坛、RoboGo 平台、用户反馈 |
| AI Dock 设置跳转 | 模型配置异常时可直达“本地模型”或“AI 引擎” |

## 设备与形态兼容性

| 功能 | RDK 设备 | 通用 Linux / Jetson / Raspberry Pi / Rockchip | 桌面客户端 | CLI |
|---|---|---|---|---|
| Moss 对话与工作区 | 支持 | 支持 | 支持 | 部分支持 |
| SSH 终端 / 文件 / 代码编辑器 | 支持 | 支持 | 支持 | 支持 |
| 远程桌面 | 支持，需板端图形服务 | 取决于目标主机环境 | 支持 | 不支持 |
| 烧录 | RDK X3 / X5 / S100 重点支持 | 可选择本机镜像写入其他介质 | 支持 | 不支持 |
| OpenClaw 部署 | RDK 设备主路径 | 默认不可部署，界面会提示限制 | 支持 | 支持部分命令 |
| 本地大模型 | 在电脑本机运行 | 在电脑本机运行 | 支持 | 不适用 |
| 技能工坊 | 可部署到设备 OpenClaw，也可写入本机 Moss | 可写入本机 Moss，设备部署受限 | 支持 | 支持部分命令 |

CLI 不承载图形界面、烧录向导、远程桌面和本地模型管理等桌面专属能力。脚本场景可以按需使用 `rdkstudio` 或 `dmoss-agent` 处理对话、设备、文件和脚本任务。
