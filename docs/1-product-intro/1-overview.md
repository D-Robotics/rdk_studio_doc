# 1.1 产品概述

**RDK Studio 是面向机器人与边缘 AI 开发的 AI 原生工作台。** 它把 Agent 对话、项目、设备连接、终端、文件、远程桌面、代码编辑、烧录和积木编程放在同一个工作环境中。

你可以先描述目标，让 Agent 结合项目和设备信息分析、规划并执行；也可以从导航打开开发工具手动操作。没有连接开发板时，仍可提问、分析附件或处理已授权的本机项目。

## 从哪里开始

| 你的目标 | 入口 |
|---|---|
| 提问、开发、排障或继续旧任务 | Agent 工作台 |
| 管理代码与任务归属 | 左侧项目与对话列表 |
| 连接或切换开发板 | 设备切换器 → 连接设备 |
| 烧录、传文件、运行命令、使用图形桌面 | 开发与设备 |
| 拖积木编排机器人程序 | 开发与设备 → 积木工作室 |
| 管理技能、MCP 等扩展 | AI 能力 → 扩展中心 |
| 下载并使用电脑本机模型 | AI 能力 → 本地大模型 |
| 配置模型或新任务运行引擎 | 设置 → AI 模型与服务 |

## Agent、模型与板端 Agent

工作台任务可以使用 **Moss** 或可用的 **DSH（DeepSeek Harness）** 运行引擎。每个任务保留自己的引擎归属；更换新任务默认引擎不会改绑旧任务。模型服务配置与运行引擎是不同设置，详见 [配置 AI 模型](../3-user-guide/13-config-center/3-ai-engine.md)。

**板端 Agent（OpenClaw）** 是部署到开发板的另一条使用路径。它需要设备连接及独立的板端配置，和工作台里的 Moss/DSH 任务分开管理。

## 项目和工作位置

新建项目时先选择主要工作位置：**本机** 或 **开发板**。后续可以补充另一端的目录。发送任务前，确认输入区显示的项目、工作位置和设备，避免把电脑路径当成板端路径。

桌面端的项目与对话保存在当前本机数据目录中；切换登录账号不会自动隐藏这些本机历史。网页版的用户数据按账号隔离。详见 [历史会话](../3-user-guide/2-ai-chat/3-multi-session.md)。

## 适用场景

- RDK 设备连接、系统烧录、ROS/TROS 开发和板端故障排查。
- 本机软件开发与板端部署配合的项目。
- 模型应用运行、日志分析和设备验证。
- 教学、机器人积木编程，以及可复用技能的整理。

RDK 是主要目标设备；通用 Linux、Jetson、Raspberry Pi、Rockchip 可复用兼容的 SSH 工作流。板型专属烧录与诊断以当前设备档案和页面提示为准。
