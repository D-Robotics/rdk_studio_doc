# 1.5 版本说明

RDK Studio 会持续更新。一般情况下，直接使用客户端里显示的界面和提示即可；日常使用时不需要记具体版本号。

## 查看和升级

打开桌面客户端，进入 **设置 → 应用与更新**，可以查看应用状态、检查更新并执行升级。升级会保留本机设备列表、模型条目、本地模型、技能、历史对话等用户数据。

命令行工具可在 **设置 → 应用与更新 → 命令行工具** 中启用或重新启用。需要在终端中确认时，可以运行：

```text
rdkstudio --version
dmoss-agent --version
```

## 升级前后

- 升级前，建议先保存正在编辑的代码和文件。
- 升级过程中不要强制退出安装器。
- 升级后如果界面显示和你看到的说明差异较大，优先在 **设置 → 应用与更新** 中检查更新状态。
- 设备、模型、技能等本地配置通常会保留；如果要换电脑，先使用配置导出功能备份。
