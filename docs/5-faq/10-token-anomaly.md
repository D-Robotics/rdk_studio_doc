# 5.10 Token 用量异常

用量偏高时，先确认当前任务引擎、模型、任务范围和是否重复执行。

## 检查内容

- 当前模型是否适合任务，是否误用成本更高的配置。
- 是否反复附上长日志、图片或整个代码目录。
- 是否有重复任务、后台运行或持续失败重试。
- 会话是否积累了大量无关上下文。

先停止不需要的任务，缩小问题范围并截取关键材料。需要更换模型时到 **设置 → AI 模型与服务**，不要再按旧版快速/思考双模式配置排查。

用量显示取决于引擎、模型提供的信息与统计范围。缺失值不等于零，用量或费用估算不等于账单；正式额度与计费以账号或模型服务平台为准。

如果看起来重复扣费或任务失败后额度异常，保留任务、时间、请求 ID 和错误信息后反馈，避免重复发起相同任务。
