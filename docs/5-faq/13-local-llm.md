# 5.13 本地大模型 / Ollama 问题

## 常见现象

- 本地大模型页显示“未安装”或“服务未启动”。
- AI Dock 横幅提示本机模型服务不可达。
- 模型已经下载，但 Moss 说模型不存在。
- 下载模型时磁盘不足或端口被占用。

## 排查顺序

1. 打开 *AI 能力 → 本地大模型*。
2. 看运行环境是否已安装。
3. 看服务是否运行。
4. 看模型列表里是否有当前配置的模型名称。
5. 点击模型测试。
6. 再设为 Moss 的快速模型。

## 关键概念

| 概念 | 说明 |
|---|---|
| 本机 Ollama | 运行在电脑上，不是运行在板端 |
| 模型名称 | 必须和 Ollama 列表中的名称一致 |
| 嵌入模型 | 不适合当 Moss 对话模型 |
| 停止服务 | 只能停止由 RDK Studio 启动的 Ollama，系统级 Ollama 需在系统里停止 |

本机 Ollama 适合作为 Moss 的快速模型；不要直接填给 OpenClaw，除非板端能访问这个模型服务。
