# 5.13 本地大模型 / Ollama 问题

打开 **AI 能力 → 本地大模型**，依次检查运行环境、服务、模型文件和工具调用能力。

| 问题 | 处理 |
|---|---|
| 未安装 / 未启动 | 安装运行环境并启动服务 |
| 端口冲突 | 检查已有 Ollama 进程，避免重复启动 |
| 模型不存在 | 核对完整名称和 tag，重新下载 |
| 测试能聊天但不能设为主模型 | 模型可能不支持工具调用，按页面检测换用支持的模型 |
| 下载失败 / 磁盘不足 | 检查网络、磁盘和数据目录；换目录不会自动迁移旧文件 |
| 工作台仍用旧配置 | 重新设为主模型配置，在 AI 模型与服务核对当前条目 |

本机模型运行在电脑上。板端 OpenClaw 必须使用板端可达的地址；电脑 `localhost` 不能直接作为板端地址。设置本机模型不改变已有任务的 Moss/DSH 引擎归属。

详见 [本地大模型](../3-user-guide/12-local-models/index.md)。
