# 5.14 串口列表为空

## 典型现象

- 系统里能看到串口，但 RDK Studio 下拉为空。
- 点击连接后提示需要先授权串口。
- 串口打开失败或被占用。

## 原因

RDK Studio 的本机串口需要你主动授权。点击 **添加** 后，在系统弹窗中选择对应串口，页面才会显示这条连接。

## 处理步骤

1. 确认电脑已经识别到这条串口线；如果系统也看不到，请先安装调试线驱动。
2. 在终端页或添加设备串口页点击 **添加**。
3. 在系统弹窗中选择调试线对应的串口。
4. 回到下拉列表选择串口和波特率。
5. 若列表中都是未知串口，点击 **清除未知串口** 后重新授权。

串口不会保存为设备。要使用 Moss 工具、文件、远程桌面、OpenClaw，请恢复网络后通过 SSH 添加设备。
