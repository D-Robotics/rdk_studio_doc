# 5.6 OpenClaw 安装失败

## 典型现象

- 板端 Agent 页显示部署失败。
- 页面提示运行依赖缺失。
- 设备离线，部署按钮不可用。
- 页面提示“安装损坏”。
- 模型配置无法同步到板端。

## 先看状态条

板端 Agent 页会同时展示 OpenClaw、模型、网络状态：

| 状态 | 处理 |
|---|---|
| 设备离线 | 先恢复 SSH，部署会暂停 |
| 缺少依赖 | 点击开始部署会尝试安装；失败时先让设备联网 |
| npm 下载失败 | 配置网络或换 npm 镜像 |
| 安装损坏 | 点击“诊断并修复”，按页面提示处理 |
| 模型不可用 | 检查板端能访问的 Base URL 和 API Key |

## 本地 Ollama 通常不能直接给 OpenClaw 用

如果 Moss 思考模型是电脑本机 Ollama，OpenClaw 通常不能直接复用。请选择板端也能访问到的远程模型服务，或在板端部署自己的模型服务。

## 排查建议

优先使用页面里的 **检查环境** 和 **诊断并修复**。如果页面已经显示部署日志，可以把日志交给 Moss，让它继续分析。

除非你熟悉板端系统维护，否则不建议直接在设备上手动改 OpenClaw 的安装目录或服务配置。
