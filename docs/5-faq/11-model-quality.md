# 5.11 模型回答质量问题

**典型现象**：模型回答跑题、重复、工具选错、输出里出现 `<think>...</think>` 原文，或中文回答里夹杂大量英文。

## 先判断这几件事

很多回答质量问题未必是模型本身太弱，先按下面顺序检查：

1. 任务是否复杂？复杂排障、代码修改和多步任务建议使用 **思考模式**。
2. 会话是否太长？如果连续追问很多轮，建议新建会话。
3. 技能是否太多？在 AI Dock 输入 `/skills` 查看本次会话启用的技能。
4. 如果以上都没问题，再考虑更换 **思考模式** 使用的模型。

## 排查清单

1. **模式选错** — 快速模式适合简短问答，不适合复杂规划。*AI Dock* 底部能看到正在使用的模型，不对就到 *设置 → AI 引擎* 调整。

2. **`<think>` 原文暴露** — 部分模型会把思考过程包在 `<think>` 标签里。看到原文时：
   - 在 *设置 → 应用与更新* 中检查更新
   - 或在模型高级设置里关闭思考过程显示

3. **中英文混杂** — *设置 → AI 引擎 → 高级* 把“回复语言”设为“跟随系统”或“中文”。如果小模型仍经常夹英文，换更强的模型更有效。

4. **工具乱选** — *AI Dock* 输入 `/skills` 查看启用的技能。用不到的技能太多时，到 *技能工坊 → 已安装* 卸载不需要的技能。

5. **会话太长** — 长会话会积累很多历史内容，模型表现可能下降。遇到明显跑题时，新建会话通常最快。

## 永久解决

- 思考模式尽量选择能力更强的模型。
- 固定流程可以到 *技能工坊 → 创建新技能*，把步骤写清楚，减少 Moss 猜错工具的概率。
- 关注 *设置 → 应用与更新* 的更新提示，模型适配和显示细节会持续优化。
