# 5.11 模型回答质量问题

回答跑题、反复尝试失败步骤或工具使用不当时，先检查任务、上下文和模型能力。

1. **核对工作位置**：项目、本机/板端目录和目标设备是否正确。
2. **明确交付结果**：说明希望得到什么、如何验证，并附上完整错误。
3. **选工作方式**：只要分析选计划；复杂需求先用 Spec；目标明确后执行。
4. **核对模型能力**：在 AI 模型与服务查看当前模型；本机主模型必须支持工具调用。
5. **处理长会话**：无关目标新建任务；重要信息保留为文件，按当前引擎支持情况压缩上下文。
6. **核对技能**：从扩展中心与输入区技能搜索检查需要的技能，不要依赖旧版 `/skills` 命令说明。

Moss 与 DSH 的模型、工具支持不同，改模型不等于换引擎。不要用“快速/思考”旧开关排查当前版本。

若回复直接暴露 `<think>` 标签或异常内部文字，保留脱敏示例，检查客户端版本并反馈。普通复制和分享默认聚焦回答，需要查看已有执行细节时使用消息更多菜单。
