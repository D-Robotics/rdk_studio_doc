# 5.12 远程桌面连接或卡顿

**典型现象**：在 *远程桌面* 页一直转圈连不上，连接后很卡，鼠标点击位置不准，画面显示不完整或黑屏。

## 先做这几步

1. 确认设备在线，终端可以正常连接。
2. 回到 *远程桌面* 页，按页面提示重新启动远程桌面。
3. 如果页面提示缺少组件，确认安装。
4. 如果只是卡顿，先降低画质或分辨率。
5. 把页面错误提示复制给 Moss，让它继续排查。

## 排查清单

### 1. 远程桌面服务未启动

第一次打开时，Studio 会自动准备远程桌面组件。失败常见原因是板端没网、磁盘满或系统组件缺失。优先使用页面里的重试或重新安装入口。

### 2. 画面卡顿

远程桌面需要占用板端和网络资源。画面越大、画质越高，越容易卡顿。两种降载方式：

- 在 *远程桌面* 工具栏降低画质。
- 降低板端桌面分辨率。

### 3. 鼠标点击错位

多发于 4K 显示器或高缩放屏幕。Studio 内右键画面，进入设置，把缩放改成 100%。

### 4. 黑屏

板端没有显示器、桌面环境未启动或远程桌面组件异常时，可能黑屏。先在页面中重新启动；仍失败时让 Moss 根据日志继续排查。

## 永久解决

- 使用 RDK 官方镜像，减少远程桌面组件缺失。
- 长期使用的设备建议固定网络，避免 Wi-Fi 波动。
- 需要长期远程办公时，先在小范围设备上验证稳定性。

## 还没解决？

按以下顺序求助：

1. 在 AI Dock 直接贴报错日志，让 Moss 结合常见 RDK 问题给出修复建议
2. 在 AI Dock 里说"帮我搜下论坛上类似的问题"，让 Moss 帮你检索社区经验
3. [RDK 官方文档](https://developer.d-robotics.cc/rdk_doc)
4. [RDK 开发者社区](https://developer.d-robotics.cc/forum)
5. Studio 内 *设置面板 → 应用与更新 → 诊断包导出*，把诊断包发给我们排查
