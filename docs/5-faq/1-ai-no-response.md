# 5.1 Agent 无响应

先判断是 **引擎不可用、模型请求失败、任务仍在运行，还是设备离线**。

## 检查顺序

1. 看输入区的 Moss/DSH 标识和当前任务状态。
2. 在 **设置 → AI 模型与服务**查看运行引擎状态；DSH 可重新检测。
3. Moss 模型请求失败时，测试当前模型，检查模型 ID、服务商、Base URL 和密钥状态。
4. 使用 Ollama 时，在本地大模型页确认服务已启动、模型已下载且支持工具调用。
5. 查看错误或消息更多菜单中的已有执行记录，再决定是否重试。

| 现象 | 优先处理 |
|---|---|
| DSH 检测失败或不可用 | 按检测原因恢复；若改用 Moss，调整默认值并新建任务 |
| API Key 无效 / 权限不足 | 在模型设置修正密钥与账号权限 |
| 模型不存在 | 核对完整模型 ID 和接口地址 |
| 请求超时 | 检查网络、代理与服务端状态 |
| 任务未停止 | 等待停止结果并核对状态，避免重复提交 |
| 设备离线 | 恢复任务绑定的设备；另一台在线设备不会替代它 |

设备离线不妨碍知识问答或本机项目工作，只限制需要访问该设备的操作。已有任务不会通过更改默认引擎自动迁移。

如果仍失败，保留版本、引擎、错误信息和请求 ID 等诊断信息，脱敏后反馈；不要把 API Key 发到对话中。
