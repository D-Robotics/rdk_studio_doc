# 5.2 SSH 连接失败

## 典型现象

在 *设备管理* 添加设备时，可能看到连接超时、密码错误、拒绝连接等提示。

先不要急着改系统配置，按下面顺序确认 Host / IP、网络和登录信息。

## 快速判断

| 页面提示 | 优先检查 |
|---|---|
| 连接超时 | 设备是否开机、Host / IP 是否填对、电脑和设备是否在同一网络 |
| 密码错误 | 用户名和密码是否正确；RDK 官方镜像常见为 `root/root` |
| 拒绝连接 | 设备远程登录服务可能没有启动 |
| 重刷系统后连不上 | 本机保存了旧设备记录，需要清理后重试 |

## 排查清单

1. **确认 Host / IP**：这里要填设备自己的 IP 或主机名，不是电脑的 IP。
2. **确认网络**：电脑和设备需要能互相访问。Type-C 直连失败请看 [5.3](./3-typec-flash-failed.md)；Wi-Fi 失败请看 [5.7](./7-network-failed.md)。
3. **确认账号密码**：RDK 官方镜像常见为 `root/root`；如果镜像改过密码，以镜像说明为准。
4. **确认远程登录已开启**：如果系统启动异常，可以先用串口登录设备，再开启远程登录服务。
5. **确认不是旧记录影响**：设备重刷系统后，删除这台设备的旧连接记录，再重新添加。

## 常见 IP 速查

| 接入方式 | 常见地址 | 怎么确认 |
|---|---|---|
| Type-C 直连 | `192.168.128.10` | 先按 Type-C 直连流程添加 |
| 网线直连 | 以镜像说明为准 | 查看镜像说明或设备屏幕/串口日志 |
| Wi-Fi / DHCP | 路由器自动分配 | 在路由器后台、系统网络列表或串口日志里查 |

## 后续建议

- 常用设备建议固定 IP，避免每次路由器重新分配。
- 添加成功后打开 *设备管理*，确认状态从“待验证”变为“在线”。
- 仍然失败时，把页面提示和 Host / IP 发给 Moss，让它继续带你排查。
