# 5.3 Type-C 直连失败

## 典型现象

- 添加设备中选择 RDK Type-C 直连后，网卡列表为空。
- 网卡显示离线或没有地址。
- 配置完成后 SSH 连不上 `192.168.128.10`。
- 连接后电脑 Wi-Fi 正常但外网不可达。

## 快速判断

| 现象 | 最可能原因 |
|---|---|
| 没有新网卡 | Type-C 线只支持充电，或设备未进入 USB 网络模式 |
| 有网卡但离线 | 设备未启动完成，或选错接口 |
| 有网卡但连接超时 | 设备没启动完成、地址不对或供电不稳 |
| 认证失败 | 镜像密码不是默认 `root/root` |
| 电脑外网断了 | 直连网卡影响了电脑的上网优先级 |

## 处理步骤

1. 换全功能 Type-C 数据线。
2. 断电重启设备，等待系统启动后点击刷新。
3. 在列表中选择插拔后新增或状态变化的网卡。
4. 若界面提示上网风险，按提示调整 Wi-Fi 优先级。
5. 仍无法认证时，改用 SSH 入口手动填写用户名、密码和 Host / IP。

## 地址约定

RDK Type-C 直连时，设备侧常见地址是 `192.168.128.10`。不要把这个地址和普通网线或 Wi-Fi 分配的地址混淆。
