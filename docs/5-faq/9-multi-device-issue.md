# 5.9 多设备目标不对

## 典型现象

- 切换设备后，Moss 似乎还在讨论上一台设备。
- 执行命令前不确定目标是哪台设备。
- 同时连接 RDK 和通用 Linux 主机，某些 RDK 专属能力不可用。

## 先看三个位置

1. 工作台输入区的设备标签。
2. 工作区里的设备名称、Host / IP、项目目录。
3. 设备列表中的在线/待验证/离线状态。

## 推荐做法

| 场景 | 做法 |
|---|---|
| 新任务和旧任务无关 | 新建会话 |
| 必须指定设备 | 在消息里写设备别名或 Host / IP |
| 设备刚添加 | 等 SSH 验证完成后再执行 |
| 非 RDK 主机 | 不要要求 OpenClaw 或 RDK BPU 专属能力 |

示例：

```text
只对 RDK-X5-工位1 执行，先检查 Host / IP 和板型，再继续。
```

打开串口不等于已经添加设备；串口日志需要你复制给 Moss，或者恢复 SSH 后正式添加设备。
