# 2.6 发起首次对话

打开 **Agent 工作台**，确认模型或引擎可用后即可开始。没有开发板时也能问问题；设备任务需要确认目标设备连接。

## 操作步骤

1. 打开工作台，按需新建项目或选择已有项目。
2. 查看工作位置条：项目、目录、本机或设备是否正确。
3. 查看 Moss/DSH 引擎标识。第一次使用可以保持当前可用默认值。
4. 选择工作方式：**执行**直接处理，**计划**只分析，**Spec**先形成可审批需求。
5. 输入目标，按需附上日志或截图后发送。

## 建议的第一条消息

已连接设备：

```text
只读检查当前设备的板型、系统版本、磁盘、内存和网络，告诉我异常和下一步建议，不修改设备。
```

未连接设备：

```text
介绍一下 RDK Studio 能帮我做什么，再给三个连接 SSH 设备后可尝试的任务。
```

本机项目：

```text
先只读检查当前项目的目录结构和启动方式，告诉我怎么验证它能运行。
```

## 查看结果

先看回答中的结果、失败或待确认事项。点击 **打开位置** 查看终端与文件；要检查已有执行细节，从消息更多菜单打开执行记录。

需要换模型时进入 **设置 → AI 模型与服务**。需要换运行引擎时，在设置修改新任务默认值，再新建任务；旧任务继续保留原引擎。
