# 2.3.1 Type-C 直连

RDK Type-C 直连适合“设备就在电脑旁，但还没有局域网 IP”的场景。RDK Studio 会帮你识别 Type-C 网卡、配置直连网络，并用默认登录信息完成设备添加。

## 适用范围

| 项目 | 要求 |
|---|---|
| 设备 | 支持 USB 网络的 RDK 设备 |
| 线材 | 全功能 Type-C 数据线，不能只支持充电 |
| 客户端 | RDK Studio 桌面客户端 |
| 权限 | 首次配置本机网卡时可能需要管理员权限 |

Type-C 直连成功后，设备会像普通 SSH 设备一样出现在设备列表里。之后文件、终端、Moss、OpenClaw 等能力都可以使用。

## 操作步骤

1. 用 Type-C 数据线连接电脑和 RDK 设备，并等待设备启动。
2. 打开 *添加设备 → RDK Type-C 直连*。
3. 在网卡列表中选择插拔后新增或状态变为在线的接口。
4. 点击 *开始连接*。RDK Studio 会配置本机网络，并尝试连接设备。
5. 连接成功后填写或确认设备别名，保存到设备列表。

常见直连地址如下：

| 端 | 地址 |
|---|---|
| 设备侧 | `192.168.128.10` |
| 电脑侧 | 与设备在同一网段的本机地址 |

界面会优先展示在线接口，也可以切换为“显示全部接口”排查离线或未识别网卡。

## 常见提示

| 现象 | 处理 |
|---|---|
| 未检测到 Type-C 网卡 | 确认线材支持数据传输，重新插拔后点刷新 |
| 网卡存在但无 IP | 确认选中了 RDK 对应网卡，再重新开始连接 |
| SSH 超时 | 等设备启动完成，确认供电稳定后重试 |
| 认证失败 | 默认用户名和密码通常为 `root/root`，若镜像改过密码请改用 SSH 入口手动填写 |
| 电脑外网突然不可达 | 可能是直连网卡影响了电脑的上网优先级，按页面提示调整网络设置 |

完整排查见 [5.3 Type-C 直连失败](../../5-faq/3-typec-flash-failed.md)。

## 后续操作

Type-C 直连适合首次接入和近距离调试。

如果后续希望拔掉数据线远程使用，建议继续 [2.4 配置网络](../4-configure-network.md)。设备接入 Wi-Fi 后，再用 Wi-Fi IP 添加一个 SSH 设备。
