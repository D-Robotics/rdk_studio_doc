# 2.5 接入 AI 模型

先打开工作台尝试当前可用模型。是否能直接使用内置模型，取决于登录状态、账号额度和部署配置；出现缺 Key 或连通性错误时，再进入 **设置 → AI 模型与服务**。

## 选择路径

| 情况 | 操作 |
|---|---|
| 当前内置模型可用 | 直接发起对话 |
| 团队已有模型服务 | 新增模型，填写服务商、模型 ID、Base URL 和 API Key |
| 想在电脑本机运行模型 | 到本地大模型安装 Ollama，下载支持工具调用的模型 |
| 想使用 DSH | 在运行引擎设置检测就绪，设为默认后新建任务 |

## 配置自己的模型

1. 打开 **设置 → AI 模型与服务**，在当前模型区域新增配置。
2. 按服务商提供的信息填写显示名称、服务商、模型 ID、API Key 和 Base URL。
3. 测试厂商 API 连通性，保存或选择 **新增并启用**。
4. 回到工作台，核对模型名称后发一条简单消息。

模型服务商和任务引擎是不同概念。已有任务不会因为你修改 Moss/DSH 默认引擎而改绑。

## 使用本机 Ollama

打开 **AI 能力 → 本地大模型**，按提示安装或检测运行环境、启动服务、下载模型并测试，然后 **设为主模型配置**。用于 Agent 的模型必须支持工具调用；能下载或能聊天，不等于能完成工具任务。

模型运行在电脑上。板端 OpenClaw 的模型地址需由板端可达，并单独配置。
