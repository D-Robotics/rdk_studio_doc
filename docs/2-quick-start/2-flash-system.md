# 2.2 烧录系统镜像

开发板没有可用系统或需要重装时，从烧录页开始。已经正常启动且有 IP 的设备可跳到 [接入设备](./3-connect-device/index.md)。烧录会覆盖目标存储，先备份重要数据。

## 选择方式

| 设备 | 流程 |
|---|---|
| RDK X3 / X5 | 按板型选择镜像，通常写入 TF/SD 卡；eMMC 型号使用对应流程 |
| RDK S100 / S100P | 支持的桌面环境可在应用内完成固件准备和写入 |
| RDK S600 | 按官方指引使用 XBurn 手动烧录，不使用 TF 卡镜像流程 |
| 其他介质 | 选择匹配设备的本机镜像文件，确认兼容性 |

## 镜像与目标确认

1. 在烧录页确认板型，选择官方镜像，或选择本机镜像/固件。
2. 按提示继续到目标磁盘或设备确认。
3. 核对介质名称、容量和路径，阅读清空提示后开始。
4. 等待下载、准备、写入及校验的实际结果，不拔线、不休眠。
5. 完成后按提示启动设备，再接入 RDK Studio。

S100 的固件可选择受支持的压缩包或文件夹；S600 进入配套工具指引。页面显示环境不支持时，按提示升级或使用官方工具。

## 网页版

支持 Web 烧录桥的页面由本机桥接程序读取镜像和写盘，需要先按指引启动并确认桥在线。桥读取的是本机绝对路径，浏览器不会直接写盘。没有桥接能力时使用桌面客户端。

详见 [烧录手册](../3-user-guide/7-system-flashing/index.md)与[S100 / S600 流程](../3-user-guide/7-system-flashing/4-s100-xburn.md)。
