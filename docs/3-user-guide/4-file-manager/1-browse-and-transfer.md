# 3.4.1 浏览和传文件

先确认本机或设备目标，再使用目录树、面包屑、路径栏或文件列表浏览。任务工作区中的目录选择器也可切换项目或更换对应文件夹。

## 上传与下载

- 上传：使用上传按钮，或在支持的文件视图拖入文件。文件夹与批量支持以当前入口为准。
- 下载：使用文件行或菜单的下载操作，再按系统保存提示选择位置。
- 传输失败：查看设备连接、目录权限和页面错误后重试。

不同文件视图不一定提供同样的批量下载、目录打包或拖出功能。以界面实际提供的操作为准，不要假定都能打包 ZIP 或拖到桌面。

## 文件操作

使用当前文件菜单创建文件/目录、重命名、删除、复制路径或在此打开终端。删除前核对位置和对象；打开终端后再次确认它面向本机还是目标设备。

名称筛选用于当前视图；需要跨目录搜索时可明确告诉 Agent 搜索范围，例如：

```text
只读查找当前板端项目目录下的 .hbm 文件，列出完整路径，不修改任何内容。
```

`/tmp` 通常用于临时文件；系统配置与模型目录因镜像而异。烧录、分区或升级是否保留某目录取决于具体流程，不能把 `/userdata` 等目录当成永不丢失的备份。
