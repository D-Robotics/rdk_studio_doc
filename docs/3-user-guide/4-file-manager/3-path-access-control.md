# 3.4.3 路径与权限

文件能否读取或修改，由工作区授权、路径限制、设备状态和操作系统权限共同决定。看到路径不代表拥有写入权限。

## 常见限制

| 情况 | 处理 |
|---|---|
| 未绑定工作目录 | 选择或授权项目目录 |
| 路径超出工作区范围 | 回到已授权目录，或使用正式的目录授权入口 |
| 设备离线 / 目标不匹配 | 恢复原目标连接后再操作 |
| 系统或敏感路径受限 | 阅读错误并核对实际需求，使用支持的操作入口 |
| 操作系统拒绝 | 检查目录所属用户、挂载状态与设备权限 |

`/sys`、`/proc`、`/dev`、`/boot` 等路径可能涉及内核、设备与启动状态，支持范围因操作不同而异。不要假定所有内容都能读取或写入。

在对话中写“我授权”不会自动突破路径限制或操作系统权限。需要确认的动作应通过对应审批或授权入口处理。被拒绝时应保留原因，不能把失败显示当成写入成功。
