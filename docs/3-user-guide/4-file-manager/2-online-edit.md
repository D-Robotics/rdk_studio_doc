# 3.4.2 编辑文件

从对应工作位置的文件列表打开文本文件，在编辑器修改并保存。它适合小型配置、脚本和文本；完整项目开发也可使用代码编辑器。

## 保存前检查

1. 确认文件属于本机还是哪台设备。
2. 确认完整路径和修改内容。
3. 使用保存按钮或界面支持的保存快捷键。
4. 等待成功提示；失败时保留编辑内容并按错误处理。

切换设备后，旧编辑内容仍属于原目标。出现来源不匹配提示时，切回原设备再保存，不要把旧内容写到新设备。

模型文件、压缩包和二进制不适合当作文本保存。需要完整副本时下载文件；大日志先用终端截取所需片段。

保存配置后是否需要重载服务取决于具体程序。先确认保存成功，再按程序说明验证生效。
