# 3.4.2 编辑文件

文件页可以直接编辑板端的小型文本文件，不需要先下载到电脑。它适合临时改配置、查看脚本、修一两行代码；如果要改整个项目，请使用 [3.5 代码编辑器](../5-remote-ide/index.md)。

## 编辑流程

| 步骤 | 操作 |
|---|---|
| 1 | 在文件页中双击目标文件 |
| 2 | 编辑器在右侧或新窗口打开 |
| 3 | 修改内容，确认没有误改路径或关键配置 |
| 4 | 按 Ctrl + S 保存，修改会写回板端 |

保存成功后会有提示。如果保存失败，例如权限不足，编辑器会显示错误信息。

## 适合编辑什么

适合直接编辑：

- 配置文件，例如 `.yaml`、`.json`、`.conf`。
- 常见脚本，例如 `.sh`、`.py`、`.js`。
- 纯文本、日志片段和 Markdown 文件。

不建议在文件页直接编辑：

- 很大的日志文件。
- 二进制文件、模型文件、压缩包。
- 涉及多个文件的完整项目。

## 遇到问题怎么办

- 提示权限不足：先确认是否真的需要改这个路径，再用 Moss 排查。
- 文件太大或打开很慢：先用终端截取一小段，或改用代码编辑器。
- 保存后程序没有生效：检查服务是否需要重新加载或重启。
