# 3.4 文件

![文件面板：工作区侧栏可切到文件视图，未选择设备或远端目录时保持只读提示](http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/rdk_studio/zh/06-file.png)

文件页用于查看和管理板端文件。你可以像在电脑上打开文件窗口一样浏览目录、上传文件、下载文件，也可以直接打开小文件进行编辑。

## 第一次使用顺序

| 顺序 | 你要做什么 |
|---|---|
| 1 | 先确认设备已在线，并且已选择远端目录 |
| 2 | 打开 **文件** 页，查看左侧目录树和右侧文件列表 |
| 3 | 需要传文件时，直接拖拽或点击上传/下载 |
| 4 | 只改一两个文本文件时，可以双击打开并保存 |
| 5 | 遇到权限不足或敏感路径，先确认是否真的需要修改 |

文件页和 Moss 看到的是同一台设备上的同一份文件。你在文件页保存的修改，Moss 后续能读到；Moss 修改过的文件，刷新文件页后也能看到。

系统目录和敏感路径可能会限制写入。遇到无法保存、权限不足或路径不可写时，先确认自己是否真的需要改这个位置，再把页面提示交给 Moss 排查。
