# 3.4 文件

文件功能分为 **任务工作区文件** 与 **设备文件管理**。本机项目可从“打开位置 → 文件”浏览已授权目录；设备文件需要目标 SSH 连接。

## 使用顺序

1. 确认当前项目、工作位置和目录。
2. 本机项目直接打开位置；板端项目先确认设备在线并绑定远端目录。
3. 使用目录树、路径栏和文件列表查看内容。
4. 按页面提供的上传、下载、创建、重命名或编辑入口操作。
5. 写入前核对目标，保存后检查结果。

两端目录分别保存。切换设备、项目或工作位置后，不能把旧文件列表当成新目标内容；加载失败时按错误处理。

## 文件与 Agent

Agent 修改的文件可在对应工作位置查看；手动保存后，也应让 Agent 重新读取最新内容。外部程序同时编辑时，保存前确认是否有覆盖冲突。
