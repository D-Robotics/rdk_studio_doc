# 3.1.2 跨页面联动

输入区的工作位置条把项目、目录和本机/设备目标放在一起。点击 **打开位置** 后，右侧显示对应任务工作区。

## 同一位置使用多个工具

| 视图 | 用途 |
|---|---|
| 概要 | 当前任务、项目、设备、产物与引用 |
| 终端 | 在本机或目标设备的位置运行命令 |
| 文件 | 查看、传输和编辑对应位置的文件 |

从文件菜单选择“在此打开终端”时，先核对打开的是本机还是板端终端。板端需要有效 SSH 连接；本机项目无需连接设备。

## 打开独立功能页

烧录、积木工作室、远程桌面、代码编辑器和板端 Agent 从 **开发与设备** 进入；扩展中心和本地大模型从 **AI 能力** 进入。

切换页面后，可以回到工作台或左侧任务列表继续当前任务。需要 Agent 分析日志、文件或诊断时，将相关内容作为附件或引用提供，避免只说“看这个”。

## 状态变化

- 板端离线：保留项目绑定与已有信息，恢复目标设备连接后再操作。
- 尚未选择目录：先在项目或工作区入口绑定对应目录。
- 引擎不可用：打开设置重新检测；更换默认引擎后需新建任务。
- 正在运行：先确认任务状态再发送补充、停止或启动新任务，避免重复执行。
