# 3.1.1 设备状态与诊断

在工作台的设备标签、工作位置和任务概要中确认当前目标与连接状态。做设备诊断前，先核对项目绑定的设备，避免把另一台在线设备当成目标。

| 状态 | 含义 |
|---|---|
| 在线 / SSH 已验证 | 可继续请求该设备的命令、文件和诊断操作 |
| 待验证 / 连接中 | 等待连接检查，不能用旧状态证明当前可执行 |
| 离线 | 可读已有历史和日志，实际设备操作需重连 |
| 未选择设备 | 可问知识或处理本机项目，设备任务先连接设备 |

## 发起只读体检

```text
只读检查当前绑定设备：型号、系统版本、CPU、内存、磁盘、温度、网络和关键服务。说明哪些信息没有采集到，不要改配置或重启。
```

Agent 会按当前引擎可用的工具收集信息。不同板型、系统、权限和连接方式能提供的字段不同；缺失字段应看具体原因，不等同于设备整体不可用。

## 核对诊断结果

查看回答中的异常、依据和建议；需要时从消息更多菜单查看已有执行记录。命令失败、超时或字段缺失都需要保留原始提示，不能当成诊断通过。

离线快照只代表上次取得的信息。本机项目的终端或文件仍可用时，也不能据此认为板端已经恢复连接。
