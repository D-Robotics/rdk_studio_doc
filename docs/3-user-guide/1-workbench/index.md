# 3.1 工作台

**Agent 工作台**用于发起任务、继续对话，并查看项目和实际工作位置。可用的运行引擎是 Moss 或 DSH，当前任务的引擎显示在输入区。

## 第一次使用

1. 打开工作台，或从左侧项目与对话列表新建任务。
2. 需要处理文件时，创建或选择项目；只问问题可以先不绑定目录。
3. 确认输入区的项目、位置、目录和目标设备。
4. 选择执行、计划或 Spec，输入目标并发送。
5. 点击 **打开位置**，查看任务工作区的概要、终端或文件。

## 创建项目

新建项目时选择主要工作位置：

| 位置 | 准备内容 | 可做什么 |
|---|---|---|
| 本机 | 选择电脑上的项目目录并按提示授权 | 本机代码开发、文件处理与命令执行，无需连接板卡 |
| 开发板 | 选择目标设备；在线后选择板端目录 | 板端开发、运行与文件管理 |

项目创建后可以补充另一端目录，形成同时包含本机与板端绑定的项目。两端目录分别保存，切换工作位置时请核对路径。

开发板离线时，项目仍保留对它的绑定。恢复该设备的 SSH 后再选目录或执行，不会自动改用其他在线设备。

## 项目、设备和任务

- **项目**组织相关任务和目录。
- **设备**决定板端操作的目标。
- **工作位置**决定当前任务默认使用本机还是板端工作区。
- **运行引擎**决定任务由 Moss 还是 DSH 执行，任务创建后保持不变。

因此，切换默认引擎不会迁移已有任务；切换设备也不应被当成旧任务已经换了目标。继续历史时先核对任务上下文。

## 打开位置

| 视图 | 用途 |
|---|---|
| 概要 | 查看当前项目、设备、任务进展、产物与引用 |
| 终端 | 在对应工作位置查看或运行命令 |
| 文件 | 检查该位置的文件与 Agent 改动 |

需要查看诊断、变更、预览等内容时，使用当前界面提供的任务或工具入口。执行失败时保留错误信息，并让 Agent 基于实际输出继续排查。

## 历史与恢复

左侧对话列表用于查找、重命名、置顶、归档和继续任务。删除项目只删除项目记录与绑定，项目聊天仍可在最近任务中找到，本机和板端文件不会因此删除。详见 [历史会话](../2-ai-chat/3-multi-session.md)。
