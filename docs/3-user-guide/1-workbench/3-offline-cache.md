# 3.1.3 离线缓存

设备离线或网络抖动时，工作台不会直接变成空白，而是显示最后一次拿到的状态，并标注设备已离线。这样你还能判断设备失联前的大致情况。

## 离线时能看到什么

| 页面状态 | 含义 |
|---|---|
| 在线 | 数据来自设备实时返回 |
| 响应慢或连接失败 | 页面会提示原因，并继续尝试恢复 |
| 离线 | 显示离线标记和最后一次状态 |

设备恢复在线后，工作台会自动更新。你通常不需要手动刷新。

## 离线数据怎么看

离线时看到的数据不是实时数据，只能作为参考：

- 先看页面上的时间提示，确认数据是什么时候更新的。
- 不要用离线数据判断设备当前温度、负载或任务状态。
- 需要继续执行设备操作时，先恢复网络或重新连接设备。

## 多设备时的工作台

工作台只显示当前激活的设备。要切换设备，可以使用顶部设备下拉框，也可以在 *配置中心 → 设备连接* 中选择另一台设备。

切换后，工作台会重新加载对应设备的数据，不会沿用上一台设备的状态。
