# 3.7.1 选择烧录方式

RDK Studio 支持三种烧录介质，分别面向不同板型与不同使用场景。你可以先看下面的对比，再选择最合适的方式。

## 三种入口对照

| 入口 | 适用场景 |
|---|---|
| TF 卡烧录 | RDK X3 / X5 常见装系统方式 |
| eMMC 烧录 | 仅在设备和镜像支持 eMMC 流程时使用 |
| RDK S100 烧录 | RDK S100 / S100P 的专用烧录流程 |

## 选择建议

| 你的板型与目标 | 推荐介质 |
|---|---|
| RDK X3 或 RDK X5 首次准备系统 | 先走 TF 卡烧录 |
| 页面显示当前设备支持 eMMC | 再按 eMMC 流程操作 |
| RDK S100 / S100P | 使用 S100 烧录流程 |

## TF 卡准备建议

有些 TF 卡不适合做系统盘。选择前请以镜像页面或板卡官方说明为准，并尽量使用来源可靠、状态良好的 TF 卡。质量较差的 TF 卡常见问题：

- 实际容量虚标，烧录中途失败
- 写入速度慢，烧录耗时明显变长
- 使用一段时间后频繁出现读写错误

## 烧录前的准备

无论使用哪种介质，烧录前都建议：

- 确认目标介质上的数据已备份（烧录会清空原有数据）
- 板端断电，避免烧录中误操作触发板启动
- PC 接好稳定电源（笔记本接电源适配器，避免烧录中休眠）
