# 3.7.4 S100 与 S600 烧录

S100 与 S600 都使用板型对应的固件和烧录流程，但当前应用内支持不同。

## S100 / S100P

1. 在桌面烧录页选择 S100 对应型号。
2. 选择官方固件，或本机 **固件压缩包或文件夹**。
3. 按提示连接 Type-C 并准备设备烧录模式。
4. 确认后点击 **开始烧录（应用内）**，等待固件准备和写入结果。

macOS 会自动准备环境，写入时可能要求管理员授权。Windows 可按界面选项说明手动进入烧录模式。固件格式和路径必须通过页面校验，不修改包内文件。

若提示当前版本不支持应用内 S100 烧录，按页面提示升级或使用官方配套工具。

## S600

S600 走 **XBurn 手动烧录**，没有应用内 S600 写入流程，也不提供普通 TF 卡镜像流程。

1. 从当前烧录页获取匹配 S600 的 XBurn 和官方说明。
2. 按说明下载并准备固件，使用 Type-C 数据线连接板卡。
3. 在 XBurn 选择对应固件目录并执行烧录。
4. 按工具实际结果确认完成，再启动并连接设备。

不要沿用旧 S100 工具或固件。工具版本与镜像兼容要求以 S600 页面当前指引为准。

## 失败排查

保留失败阶段、错误信息、固件来源与工具版本。先检查数据线、USB 连接、烧录模式和固件完整性；重试前等待原写入进程结束。更详细的板卡操作见 [RDK 官方文档](https://developer.d-robotics.cc/rdk_doc)。
