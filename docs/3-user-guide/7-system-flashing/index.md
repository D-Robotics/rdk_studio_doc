# 3.7 烧录

从 **开发与设备 → 烧录**选择板型与系统镜像，再确认目标磁盘或设备。烧录会覆盖目标介质，开始前备份数据并核对目标。

| 场景 | 操作 |
|---|---|
| RDK X3 / X5 TF 卡 | 选择官方镜像或本机镜像，插卡后选择目标盘 |
| X5 eMMC | 使用匹配该型号的 eMMC 流程 |
| S100 / S100P | 使用当前桌面环境支持的应用内固件准备与写入 |
| S600 | 按页面打开官方 XBurn 指引，手动选择固件和烧录 |
| Web 烧录桥 | 先在电脑启动桥，在线后由桥扫描与写盘 |

系统盘、内置盘等可能因保护策略隐藏，不能通过更换板型绕过目标限制。写入时保持电源和数据线稳定，等待真实结果。

让 Agent 打开烧录页或做烧录前检查，不等于已经获得写盘授权或开始写入。以烧录页的明确确认与实际进度为准。
