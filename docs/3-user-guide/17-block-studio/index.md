# 3.17 积木工作室

从 **开发与设备 → 积木工作室**进入图形化编程。选择机器人或示例后，把积木拖到画布连接成程序，先在仿真里验证，再按需运行到设备。

## 第一次使用

1. 从机器人或示例列表选择一个条目，查看说明。
2. 在画布连接积木，填写参数。
3. 点击 **仿真**，观察舞台和运行日志。
4. 需要修改时先停止，调整积木后重新运行。
5. 使用 **保存项目**，或从文件菜单导出项目/案例。

仿真无需开发板。仿真结果只说明模拟执行情况，不证明真实硬件或设备命令已运行。

## 运行到设备

1. 连接并验证目标设备，确认机器人包与当前设备匹配。
2. 先停止当前仿真或运行，查看即将执行的程序与目标。
3. 点击 **运行到设备**，按页面提示确认。
4. 查看真实运行日志、失败原因和结果，完成后停止运行。

运行中会禁用冲突操作；仿真与真机不能同时运行。离线、目标变化、程序校验失败时先解决提示，不要用仿真成功代替真机验证。

## 保存与交换

| 文件 | 内容 |
|---|---|
| `.rdkdevice.json` | 机器人配置/积木定义 |
| `.rdkproject.json` | 积木项目 |
| `.rdkcase.json` | 同时包含配置与项目的案例包 |

使用文件菜单导入或导出项目与案例，机器人包菜单用于配置导入、导出或删除。ZIP 文件需按提示解压，再导入受支持的文件。

内置示例为只读，修改后需要另存副本。切换项目、导入或离开页面前保存重要内容；导出的文件适合跨环境备份，浏览器本地草稿不能代替独立备份。

## 遇到问题

- 没有积木或无法编译：确认已选择有效机器人配置，并按校验提示修正参数。
- 运行到设备不可用：检查设备连接、当前运行状态和配置是否支持设备执行。
- 页面切换或设备变化后结果异常：先停止，再核对目标和日志后重新发起。
