# 3.10.5 处理板端任务

有些任务更适合在板端处理，例如依赖设备状态、板端模型或板端技能的任务。OpenClaw 页面会根据设备状态展示可用操作。

## 把任务交给 OpenClaw

Moss 判断任务适合板端处理后，会引导你进入板端 Agent 页面。典型流程如下：

1. 你在 AI Dock 中描述需求，例如：“帮我检查板端关键服务状态”。
2. Moss 检查设备是否满足要求。
3. 如果条件满足，Moss 会说明计划并请求确认。
4. 你确认后，OpenClaw 或对应页面会继续处理。
5. 处理结果会回到 Studio，方便你继续追问或排查。

## 网络波动时

当普通 SSH 执行遇到超时或网络抖动时，Studio 会在界面里显示失败原因。你可以根据提示重试、检查网络，或让 Moss 帮你判断是否适合进入板端 Agent 页面。

涉及高风险操作时，仍然需要你确认。

## 任务结果

OpenClaw 处理任务后，关键结果会显示在 Studio 中。例如：

- 检查结果
- 执行日志
- 失败原因
- 需要你确认的下一步

如果设备离线，Studio 会按页面状态提示你先恢复连接。

## 何时不建议交给 OpenClaw

下面这些场景，直接使用 Moss + 终端通常更清楚：

| 场景 | 原因 |
|---|---|
| 你明确说"在 PC 上做" | 按你的指令处理 |
| 任务只涉及本机文件 | OpenClaw 处理的是板端设备 |
| 任务需要复杂分析 | 先用 Moss 整理计划更稳 |
| 任务很快能完成 | 直接在终端或工作台完成即可 |
