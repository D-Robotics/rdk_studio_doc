# 3.10.1 判断是否需要 OpenClaw

OpenClaw 不需要一开始就安装。这里帮你判断什么时候需要安装 OpenClaw，什么时候先用 Moss + SSH 就够。

## 先判断是否需要

| 你要做什么 | 建议 |
|---|---|
| 日常问答、看日志、整理步骤 | 先用 Moss |
| 偶尔通过 SSH 跑命令 | 先用终端或 Moss |
| 使用板端技能、板端模型或设备侧消息通道 | 再部署 OpenClaw |

## 常见场景

| 场景 | 是否需要 OpenClaw |
|---|---|
| 偶尔通过 SSH 跑命令 | 不需要，终端就够 |
| 让 AI 帮跑命令（PC 在线） | 不需要，Moss 可以通过已连接设备执行，并在界面显示输出 |
| 需要板端技能或板端模型 | 通常需要 |
| 需要把消息通道接到设备侧 | 按页面提示部署 |
| 希望任务直接围绕这台设备处理 | 可以考虑 |

简单说：**临时调试先用 Moss + 终端；需要板端助手时，再进入板端 Agent 页面。**

## 示例

- “帮我检查板上的温度和关键服务，发现异常先告诉我。”
- “我希望团队成员在群里查询板端状态。”
- “板端的关键服务异常了，我想先排查原因，再决定是否重启。”

这类任务可能影响设备状态，建议先让 Moss 给出排查步骤。需要实际执行时，按界面提示确认。

## 不适合 OpenClaw 的场景

| 场景 | 原因 |
|---|---|
| 板端资源明显紧张 | 板端服务会占用一些资源 |
| 板端镜像缺少运行环境 | OpenClaw 需要先安装运行组件 |
| 单次任务 | 直接用 Moss + 终端更简单 |
| 板端无法访问外部网络 | 安装时可能无法下载依赖 |

如果只是短期调试，而且电脑会一直在线，可以先不安装 OpenClaw，使用 Moss + 终端即可。
