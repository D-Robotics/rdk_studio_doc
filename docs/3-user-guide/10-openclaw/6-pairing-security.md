# 3.10.6 配对和确认

OpenClaw 会和 RDK Studio 建立安全连接。日常使用不需要手动配置网络服务，也不建议把板端服务直接暴露到公网。

## 首次使用

首次访问 OpenClaw 时，Studio 会完成必要的连接授权。这个过程通常自动完成；如果需要你确认，页面会直接给出提示。

## 安全入口

日常使用中，Studio 会自动完成连接。你主要在以下入口处理安全相关动作：

| 入口 | 说明 |
|---|---|
| 部署与连接 | 查看状态、诊断异常、重启或卸载板端 Agent |
| 模型 | 管理板端可用模型，避免把仅电脑本机可达的地址填给板端 |
| 接入飞书 | 管理外部消息通道的凭据、启停和配对用户 |

## 使用建议

- 优先通过 RDK Studio 或受控网络访问 OpenClaw。
- 不要把 OpenClaw 服务直接暴露到公网。
- 外部消息通道需要绑定用户，并按页面提示处理确认。
- 涉及写文件、执行命令、重启服务等操作时，先确认设备和影响范围。

## 高风险操作

OpenClaw 可以配合 Moss 执行设备操作。遇到高风险操作时，页面会要求你确认；请先看清目标设备、操作内容和可能影响，再决定是否继续。
