# 3.10.2 部署和卸载

OpenClaw 的部署是一键操作。Studio 会完成环境检查、依赖安装和服务启动；你不需要手动登录板端配置。

## 部署前的环境要求

部署前先确认三件事：

- 设备已通过 SSH 添加并在线。
- 设备网络可用，安装期间能获取所需文件。
- 设备有足够空间，当前账号有安装权限。

如果条件不满足，页面会提示下一步怎么处理。

## 一键部署流程

1. 进入 *板端 Agent* 页
2. 看到未安装提示后，点击 *一键部署*
3. 查看环境检查结果，确认无明显问题
4. 点击 *确认安装*
5. 等待页面显示 OpenClaw 已就绪

弱网环境下部署会更慢，等待过程中不要频繁关闭页面或重启设备。

## 部署失败的常见原因

| 现象 | 原因 | 解决 |
|---|---|---|
| 准备环境失败 | 设备环境或权限不满足要求 | 按页面提示处理后重试 |
| 下载或同步很慢 | 设备网络不稳定 | 检查网络后重新部署 |
| 启动失败 | 安装完成但服务没有正常启动 | 点击诊断并修复，或把页面提示交给 Moss |
| 提示目录不可写 | 安装目录没有写入权限 | 按页面建议选择可写目录 |

完整的故障排查见 [5.6 OpenClaw 安装失败](../../5-faq/6-openclaw-install-failed.md)。

## 升级与卸载

| 操作 | 入口 | 行为 |
|---|---|---|
| 诊断并修复 | *部署与连接* 页签中的诊断入口 | 检查 OpenClaw 状态，并尝试修复常见异常 |
| 重启服务 | *部署与连接* 页签中的恢复操作 | 常用于连接异常恢复 |
| 重新部署 / 升级 | *部署与连接* 页签中的重新部署入口 | 拉取并重装 OpenClaw；保留必要配置 |
| 卸载 | *部署与连接* 页签中的卸载入口 | 停止服务并移除 OpenClaw，操作前会要求确认 |

诊断和重启服务通常用于恢复异常。重新部署和卸载会改变板端环境，执行前请确认当前设备和正在运行的任务。
