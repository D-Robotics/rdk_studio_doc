# 3.10.4 和 Moss 配合使用

电脑端的 Moss 可以与板端 OpenClaw 配合工作。你只需要知道：Moss 负责理解你的需求，OpenClaw 负责处理更贴近当前设备的部分。

## 怎么配合

1. 你在 AI Dock 中描述任务。
2. Moss 判断是否需要进入板端 Agent 页面。
3. 如果需要，Moss 会检查 OpenClaw 状态和板端模型是否可用。
4. 你确认后，任务会进入对应流程，执行结果会在界面里显示。

连接和安全校验由 Studio 自动处理，不需要你手动开放板端服务。

## Moss 可以帮你做什么

当你在 AI Dock 中提到 OpenClaw 相关话题时，Moss 会按页面状态引导你：

- 检查 OpenClaw 是否安装、是否在线、模型是否可用。
- 引导你完成部署、卸载、重启或诊断修复。
- 帮你检查板端模型、飞书或微信通道配置。
- 判断任务是否适合进入板端流程，并在继续前提示你确认。

你通常不需要先记住入口名称。在 AI Dock 中用自然语言描述需求即可，Moss 会根据任务引导你使用合适的页面；涉及设备状态变化时，会在继续前提示确认。

## 状态异常时

工作台和板端 Agent 页会显示 OpenClaw 是否就绪。遇到异常时，页面会给出提示，例如需要重新部署、检查模型配置或等待设备恢复在线。

如果你不确定怎么处理，可以把页面提示发给 Moss，让它帮你判断下一步。部署、卸载、重启这类会影响设备状态的操作，继续前都会提示确认。
