# 3.10.3 查看状态和配置

**板端 Agent** 页围绕“状态摘要、控制面板、板端对话”组织。第一次使用时，先看顶部状态，再按页面提示部署、修复或配置模型即可。

## 顶部状态

页面顶部会集中显示板端 Agent 的关键状态：

- 设备：当前设备是否在线、是否可通过 SSH 操作。
- 助手：OpenClaw 是否已安装、连接服务是否正常、安装是否损坏。
- 板端外网：板端是否能访问部署和模型所需的网络。
- 模型：板端 Agent 当前能否使用可达模型。

状态异常时，页面会给出下一步动作，例如部署板端 Agent、诊断并修复、配置模型或检查网络。

## 控制面板

页面右侧的控制面板有 3 个页签：

| 页签 | 作用 | 常见操作 |
|---|---|---|
| 部署与连接 | 安装、运行和恢复 OpenClaw | 检查环境、一键部署、取消部署、诊断并修复、重启连接服务、卸载 |
| 模型 | 板端 Agent 使用的模型配置 | 跟随 Moss 思考模型，或填写 Base URL、模型 ID、API Key 并同步配置 |
| 接入飞书 | 板端飞书通道配置 | 填写飞书应用信息、启动/停止通道、处理配对用户 |

## 配置状态清单

页面会显示“配置状态”清单，通常包括：

- 板端 Agent：未安装、安装损坏、已安装、连接服务运行中、运行中但板端未联网。
- 模型：未配置、已选模型但缺凭据、配置可用。
- 飞书：未配置或已配置。

每个状态项旁边都有对应动作，例如“部署板端 Agent”“诊断并修复”“配置”“修改”“查看”。

## 快捷任务与板端对话

页面会提供几个快捷提示，点击后会打开对应操作：

| 快捷项 | 作用 |
|---|---|
| 体检 | 运行一次设备和 Agent 健康检查 |
| YOLO | 在当前设备上运行 YOLO 示例并返回结果 |
| 报错 | 结合最近板端日志解释错误原因 |
| 连接 | 检查板端 Agent 连接状态 |

当设备、网络和模型都可用时，可以在页面底部直接与板端 Agent 对话。板端 Agent 更适合处理这台设备上的任务；跨设备协调、电脑本机文件和复杂问题仍优先交给 Moss。
