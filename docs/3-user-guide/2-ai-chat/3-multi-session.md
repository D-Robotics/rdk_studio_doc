# 3.2.3 查看历史会话

通过左侧项目与对话列表查找和继续任务。支持搜索、重命名、置顶、归档等操作；继续前确认项目、设备、工作目录和任务引擎。

## 新建还是继续

继续同一目标时留在原会话；目标无关、项目不同或需要换运行引擎时新建任务。已有任务保留 Moss/DSH 归属，修改新任务默认引擎不会迁移它。

长会话可能压缩较早内容。重要日志、配置和结论应保留为文件或附件；使用 `/compact` 的可用性以当前引擎为准。

## 桌面本机历史

项目、聊天、标题、置顶、归档和草稿保存在当前本机数据目录。退出登录或切换账号后，这些已保存记录仍可查看；新执行使用当前账号权限和额度。不同系统用户或数据目录的历史不会自动合并。

| 操作 | 影响 |
|---|---|
| 删除项目 | 移除项目记录与绑定；聊天保留在最近任务，本机和板端文件保留 |
| 从本机历史删除 | 对使用同一数据目录的账号生效，阻止保留的旧来源再次出现在列表 |
| 永久删除 DSH 对话 | 单独的官方会话删除操作，仅供当前账号有权删除的 DSH 对话使用 |

从本机历史删除不等于永久删除官方 DSH 对话。执行永久删除前核对对象与确认提示。

## 升级恢复

新版会复制并校验旧本机历史，保留原来源。空间不足或恢复失败时，先恢复存储与本地服务，再选择 **重试本机历史恢复**。只读恢复状态下保留原记录，不要通过删除旧记录或重置应用来排障。

回退旧版不会自动导入新版新增聊天。保留数据目录，重新运行新版后可继续恢复。

## DSH 与账号切换

本机 DSH 历史可用于查看已保存内容；继续执行以官方会话为准。跨账号继续会创建当前账号的关联任务并保留原记录，旧账号任务与审批不会交给新账号接管。

Web 部署的对话、项目和任务数据按账号隔离，不能套用桌面本机历史共用规则。

## 停止后继续

停止不会回滚已经完成的命令、文件写入或设备状态。继续时说明目标，并先核对上次结果，避免重复执行。
