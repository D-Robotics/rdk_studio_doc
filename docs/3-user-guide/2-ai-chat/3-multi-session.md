# 3.2.3 查看历史会话

Moss 会话保存在本机。你可以通过历史抽屉、工作区信息和当前设备标签组织任务。

## 新建会话

点击 Dock 顶部的 **新对话** 可开启一个空白对话。适合以下情况：

- 上一个任务已经结束，想开始另一个主题。
- 当前会话 Token 较高，早期内容已被压缩。
- 设备、项目或目标发生变化，不想混入旧任务信息。

## 继续历史

通过历史按钮可以打开本地对话列表。继续历史时，Moss 会读取该会话的消息、执行结果和摘要；如果当前设备或项目已经变化，建议先说明新的目标，避免沿用旧假设。

## 长会话自动整理

长会话接近模型可处理内容上限时，RDK Studio 会整理较早的内容，只保留摘要和近期消息。这样可以继续对话，但早期细节会变少。重要日志、配置和结论建议作为附件或文件保留。

## 取消与继续

任务执行中可以取消。取消后，已经完成的命令、文件写入或设备操作不会回滚；下一条消息可以说“从刚才失败的步骤继续”，Moss 会尽量从最后的运行记录接着推进。

## 多设备建议

多设备操作时，避免在同一条消息中含糊地说“那台板”。建议使用设备别名、Host 或工作区标签明确目标。
