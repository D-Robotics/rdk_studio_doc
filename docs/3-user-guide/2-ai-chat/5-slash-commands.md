# 3.2.5 使用快捷命令

斜杠命令是在 AI Dock 输入框中以 `/` 开头的快捷指令，用来管理当前会话、查看技能或临时切换模型。这类命令不会发给大模型，也不消耗 Token。

## 命令清单

| 命令 | 作用 |
|---|---|
| `/help` | 显示可用斜杠命令的清单与说明 |
| `/clear` | 清空当前会话的参考信息，从空白对话重新开始（保留会话记录） |
| `/sessions` | 列出历史会话，可选择一个会话继续 |
| `/skills` | 列出当前会话已加载的技能 ID 与简要说明 |
| `/model` | 临时切换当前对话使用的模型（仅本会话生效） |
| `/reset` | 重置 Moss 状态：清空当前对话信息、重新加载可用功能、重新探测设备 |

## 典型使用场景

### `/clear` vs 新建会话

`/clear` 清空当前会话的参考信息，但保留会话记录，适用于“在同一个会话里换个话题继续”。新建会话更适合“开始一个全新的任务”。你可以根据场景选择。

### `/skills` 验证技能加载

如果你怀疑某个技能没被 Moss 自动加载（比如安装了某个技能，但回复看起来没用上），可以输入 `/skills` 查看当前会话实际激活的技能清单。

技能加载是按需的：你的消息命中 trigger 关键词时，相关技能才会被加载。

如果描述和技能的 trigger 不匹配，可以在 [3.11 技能](../11-skill/index.md) 中调整 trigger 关键词。

### `/model` 临时换模型

某次对话需要更强的模型（例如复杂代码生成），可以临时用 `/model` 切换：

```
/model claude-sonnet-4-20250514
```

切换后立即生效，仅影响本会话，不修改全局默认配置。会话结束或新建后恢复到默认模型。

### `/reset` 处理 Moss 异常

当 Moss 看起来“卡住了”，例如反复尝试同一个失败操作、回复明显偏离当前问题，可以用 `/reset` 重置。

这会清空当前对话信息、重新加载可用功能、重新探测当前设备，比 `/clear` 更彻底。
