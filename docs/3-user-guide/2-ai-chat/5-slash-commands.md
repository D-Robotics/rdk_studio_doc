# 3.2.5 使用快捷命令

在输入框键入 `/` 查看当前命令菜单。部分命令直接打开设置或控制任务，部分会展开成任务要求交给 Agent，因此可能使用模型、工具和额度。

## 常用命令

| 命令 | 用途 |
|---|---|
| `/plan <需求>` | 切到计划模式，只形成步骤与风险 |
| `/build <需求>` | 开发可在 RDK 上运行的应用 |
| `/debug <问题>` | 按证据排查与修复问题 |
| `/learn <主题>` | 结合技能和文档讲解，可提议沉淀经验 |
| `/review <对象>` | 上板前审查代码或配置 |
| `/team <问题>` | 请求专家团从多个角度取证并汇总 |
| `/goal set <目标>` | 设置可恢复目标；`/goal status` 查看状态 |
| `/compact` | 压缩当前会话上下文 |
| `/settings` | 打开设置 |
| `/stop`、`/stop-all` | 请求停止当前任务或全部相关任务 |

`/skill <技能名> [任务]` 可手动输入，也可从技能搜索入口选择；它不一定显示在 `/` 菜单中。菜单还可能提供一句话生成应用、运行或部署生成应用等命令，使用前查看参数提示。

## 示例

```text
/plan 给当前项目增加摄像头预览，先说明依赖、风险和验证步骤
/debug 当前板卡的 ROS 2 节点启动失败，先只读收集日志
/skill rdk-app-development 做一个设备状态网页
```

命令可用性取决于运行引擎和当前部署。Moss 命令与专家团能力不表示 DSH 自动具备同样支持；遇到不支持时按提示处理，不会自动换引擎执行。

模型请通过输入区模型选择器或 **设置 → AI 模型与服务** 调整；历史请通过对话列表管理。
