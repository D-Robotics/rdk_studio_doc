# 3.2 AI Dock

AI Dock 是 Moss 的输入区。可以先从 **核心 → 工作台** 打开它，再按“确认设备 → 选择方式 → 输入问题 → 查看结果”的顺序使用。

## 第一次使用顺序

| 顺序 | 你要做什么 |
|---|---|
| 1 | 打开 **核心 → 工作台**，找到底部输入区 |
| 2 | 看输入区设备标签，确认是否绑定到正确设备 |
| 3 | 不确定风险时选 **计划**，明确要操作时选 **执行** |
| 4 | 简单问题用 **快速**，排障和代码任务用 **思考** |
| 5 | 发送消息后，看对话、终端、文件或诊断里的结果 |

## 常用控件

| 控件 | 选项 | 作用 |
|---|---|---|
| 设备标签 | 当前设备 / 未绑定设备 | 告诉 Moss 当前任务是否能直接触达设备 |
| 工作方式 | 执行 / 计划 | 执行会直接处理任务；计划会先列步骤、风险和确认点 |
| 回复模式 | 快速 / 思考 | 快速适合简单问答；思考适合复杂排障与多步任务 |
| 附件 | 文件 / 图片 / 截图 | 把日志、配置、截图、代码片段交给 Moss 参考 |

## 与工作区的关系

Moss 对话在左侧主列，工作区面板在右侧。你可以一边让 Moss 分析，一边打开终端、文件、变更、诊断或历史面板。Moss 回复时会参考当前页、设备、项目目录和你选中的引用。

## 离线与模型异常提示

输入区会显示两类重要横幅：

- **设备离线**：Moss 可以继续做方案和知识回答，但设备执行会等待重连或再次确认。
- **模型配置异常**：快速或思考模型指向本地 Ollama、但服务未启动或模型未下载时，横幅会提供“本地模型”或“AI 模型设置”跳转。

## 历史与快捷命令

AI Dock 会保存本地对话历史，你可以新建会话，也可以回到历史会话继续任务。输入区支持少量快捷命令，适合清空当前对话信息、切换模型或查看帮助；不确定时直接用自然语言描述需求即可。
