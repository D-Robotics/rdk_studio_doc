# 3.2 AI Dock

AI Dock 是工作台的任务输入区。发送前，确认 **项目与工作位置、任务引擎、工作方式、模型和附件**。

## 工作方式

| 方式 | 行为 | 适用场景 |
|---|---|---|
| 执行 | 在权限范围内直接处理任务并使用工具 | 目标明确，希望开始开发或排障 |
| 计划 | 只分析和列出步骤，不做修改 | 先了解方案、影响与风险 |
| Spec | 先形成可审批的需求与步骤，批准后开始执行 | 复杂需求，需要先对齐目标和验收标准 |

三种工作方式与运行引擎、模型选择相互独立。不要把“计划”当成执行成功，也不要把 Spec 批准当成后续所有敏感操作都已授权。

## 常用控件

| 控件 | 用途 |
|---|---|
| 工作位置条 | 查看项目、目录、本机/设备目标，打开位置 |
| Moss / DSH 标识 | 查看当前任务引擎，点击进入运行引擎设置 |
| 工作方式 | 选择执行、计划或 Spec |
| 模型 | 在可用配置中选择模型；只有默认别名时可能隐藏重复选择器 |
| 技能 | 搜索并引用技能 |
| 附件与语音 | 添加任务材料或录音转写 |
| 发送 / 停止 | 发起任务或请求停止当前执行 |

## 结果与历史

回复优先展示业务结果、必要操作与真实错误。查看已有执行细节时，从该条消息的更多菜单打开执行记录。普通复制或分享以回答内容为主，代码和命令示例仍保留。

历史和项目任务从左侧列表继续；切换新任务默认引擎不影响已有会话。没有设备时仍可提问，板端动作需要对应设备在线。
