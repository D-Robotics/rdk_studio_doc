# 3.2.1 打开 AI Dock

从左侧 **Agent 工作台** 开始，或从项目与对话列表打开任务。板端 Agent 页面中的 OpenClaw 对话是独立入口。

## 发送前检查

1. **项目与目录**：需要处理文件时，确认是本机目录还是板端目录。
2. **目标设备**：设备相关任务确认设备标签和在线状态。未连接时可以先问知识或方案。
3. **运行引擎**：输入区显示 Moss 或 DSH；点击标识会打开设置。设置只改变新任务的默认引擎。
4. **工作方式**：执行用于行动，计划用于只读分析，Spec 用于先对齐需求并审批。
5. **模型与材料**：按需选模型，附上截图、日志或文件，再发送。

## 第一条消息

已连接设备时：

```text
只读检查当前设备的型号、系统、磁盘、内存和网络状态，列出异常，不要修改配置。
```

未连接设备时：

```text
我还没有接入开发板，介绍一下现在可以做什么，并给出连接后的三个示例任务。
```

## 发送后

查看回复、审批提示和真实结果。点击“打开位置”查看概要、终端和文件；需要检查已有执行记录时打开消息更多菜单。任务失败时保留错误信息，再补充要求继续排查。

想开始不相关的新目标时新建任务；想延续同一目标时继续当前对话。需要改用另一运行引擎时，先在设置调整默认值，再新建任务。
