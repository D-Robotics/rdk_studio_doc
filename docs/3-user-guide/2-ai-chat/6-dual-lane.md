# 3.2.6 运行引擎与模型

当前版本分别选择 **任务运行引擎**、**工作方式**和**模型配置**。旧版“快速/思考”的双模式说明不再适合作为当前输入区操作指引。

| 设置 | 决定什么 | 入口 |
|---|---|---|
| 运行引擎 | 由 Moss 或 DSH 执行新任务 | 设置 → AI 模型与服务 → 运行引擎 |
| 工作方式 | 执行、计划或 Spec | 输入区工作方式菜单 |
| 模型 | Agent 使用的模型服务条目 | 输入区模型选择器、AI 模型与服务 |
| 推理深度 | 支持该能力的模型/Agent 的推理设置 | 当前界面提供的推理深度选项 |

## 改用 DSH

1. 打开 **设置 → AI 模型与服务**。
2. 查看 DSH 状态，必要时点击 **重新检测运行引擎**。
3. 检测就绪后，将新任务默认引擎设为 DSH。
4. 新建任务，确认输入区引擎标识，再发送消息。

已有任务仍使用原引擎。检测失败或不可用时按原因处理；DSH 不会自动回退到 Moss。若要使用 Moss，改回默认值并新建任务。

## 更换模型

Moss 使用已配置的模型条目；可从输入区选择或在设置中新增和测试。仅有默认 Moss 别名时，重复的模型选择器可能隐藏。

修改 Moss 模型配置不等于配置了 DSH，也不等于改变了任务引擎。可用模型和工具以当前引擎的实际状态为准。

本机 Ollama 下载后可 **设为主模型配置**，模型需要支持工具调用。详见 [本地大模型](../12-local-models/index.md)和[模型设置](../13-config-center/3-ai-engine.md)。
