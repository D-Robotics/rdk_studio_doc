# 3.3 终端

终端可以面向 **电脑本机** 或 **SSH 设备**。发送命令前，核对标签中的目标和当前目录。

## 选择终端

| 需求 | 操作 |
|---|---|
| 在电脑上的项目里运行命令 | 选择本机项目，从“打开位置 → 终端”进入 |
| 在板端运行命令 | 确认目标设备 SSH 在线，从终端页或任务位置打开 |
| 查看启动日志 | 使用当前平台支持的串口入口；串口不等于 SSH 设备接入 |

先运行 `pwd` 等简单命令核对目录，再执行开发任务。本机与板端目录分别绑定，路径名称相同也不代表同一份文件。

## Agent 输出与手动终端

Agent 的命令和结果可在对话执行记录或对应任务工具中查看，不一定复用你手动打开的终端会话。停止 Agent 请使用任务停止入口；手动终端中的 Ctrl+C 用于中断该终端前台命令。

断线重连后先检查进程状态，避免重复启动服务或重复执行写入。
