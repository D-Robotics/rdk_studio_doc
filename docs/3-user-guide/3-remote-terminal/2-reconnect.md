# 3.3.2 断线重连

终端在网络波动或设备短暂不可达时，不会立刻关闭会话，而是会尝试自动重连。这样你跑长任务、看日志时，不会因为网络轻微抖动就马上断开。

## 你会看到什么

| 场景 | 页面表现 |
|---|---|
| 网络短暂波动 | 顶部出现重连提示，Studio 会自动重试 |
| 设备重启后恢复 | 连接恢复后，终端会继续可用 |
| 主动关闭终端标签 | 会话结束，不会继续重连 |

重连期间，已经输入但还没发送的内容通常会保留。设备断开期间产生的新输出可能无法完整补回，所以关键命令建议等连接稳定后再执行。

## 重连仍失败

如果多次重连仍失败，先检查设备电源、网络、Host / IP 和 SSH 服务。常见提示可以这样理解：

| 提示 | 建议操作 |
|---|---|
| `Connection refused` | 设备在线，但 SSH 服务可能没有正常响应 |
| `Connection timed out` | 电脑暂时连不到设备，先检查网络和地址 |
| `Host key changed` | 设备可能重刷过系统，需要按页面提示重新确认 |

完整的故障排查见 [5.2 SSH 连接失败](../../5-faq/2-ssh-failed.md)。
