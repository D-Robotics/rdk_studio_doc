# 3.3.1 打开 SSH 终端

SSH 终端面向当前指定设备。打开后先检查设备名和目录，再用 `pwd`、`uname -a` 等只读命令验证。

## 多标签

可以为不同工作打开终端标签。每个 SSH 会话的目录、环境变量和前台命令相互独立；一个标签的 Ctrl+C 不会自动停止其他标签。

切换设备或打开新标签后重新核对目标。不要仅凭上一条提示符判断当前设备。关闭会话也不保证板端后台进程已停止，需要用设备上的进程或服务状态确认。

## 与 Agent 配合

手动终端适合试命令和查看输出；将相关日志引用或附给 Agent 可继续分析。Agent 的工具执行可能使用独立会话，不能假定会继承手动终端中的 `cd` 或环境变量。

停止 Agent 使用任务停止入口；手动终端中断只控制该会话的前台命令。
