# 3.3.1 打开 SSH 终端

终端支持同时打开多个 SSH 标签，每个标签互不干扰。这样你可以一个标签跑长任务，另一个标签查看状态。

## 标签的独立性

每个标签是一次独立的 SSH 会话，意味着：

- 在标签 A 中跑的环境变量、cd 路径、shell 函数不会影响标签 B
- 标签 A 的命令被中断（Ctrl+C）不影响标签 B 中正在运行的命令
- 关闭某个标签只断开该标签的 SSH 会话，板端如果有用 `nohup` 起的进程会继续运行

## Moss 执行时你能看到什么

Moss 需要在设备上执行命令时，命令和输出也会在终端中显示。这意味着：

| 触发者 | 命令显示位置 |
|---|---|
| 你在终端手动输入 | 当前标签 |
| Moss 执行设备命令 | 同样在当前标签实时显示 |

这样你可以看到 Moss 执行了哪些命令。如果 Moss 执行的命令不符合预期，你可以按 Ctrl+C 在终端中中断，同时 AI Dock 中的任务也会同步取消。

## 切换设备时的标签行为

切换当前激活设备时，终端默认在新标签中打开新设备的会话，旧设备的标签保留。这样切换设备时，不会把已经跑起来的长任务断掉。如果不需要保留旧标签，可以手动关闭。

## 常用操作

- 中断正在运行的命令：使用终端里常见的中断按键。
- 复制输出：选中需要的文本，再按系统习惯复制。
- 粘贴命令：先确认命令内容，再粘贴执行，避免误操作。
