# 3.14 消息渠道

消息渠道可以把飞书、微信里的消息转给 Moss，用于查询设备状态、查看任务结果，或触发你已经配置好的操作。设置入口位于 **配置中心 → 消息渠道 · 飞书 / 消息渠道 · 微信**。

## 使用顺序

| 顺序 | 你要做什么 |
|---|---|
| 1 | 先在 Studio 内确认 Moss、设备和模型都能正常使用 |
| 2 | 再选择飞书或微信通道 |
| 3 | 填写或扫码完成绑定 |
| 4 | 先发一条简单测试消息 |
| 5 | 确认权限和白名单后，再让团队成员使用 |

RDK Studio 会区分消息来自哪里，目前支持四类：

| 来源 | 说明 |
|---|---|
| Studio | 桌面客户端的 AI Dock |
| 飞书 | 飞书机器人 |
| 微信 | 个人微信 |
| 板端 Agent | OpenClaw 相关的设备侧消息 |

飞书、微信属于外部通道。涉及写文件、执行命令、重启服务或发送外部消息时，页面会要求确认。

配置外部通道时，请只给可信成员使用。不确定影响范围时，先回到 Studio 内查看设备状态。
