# 3.11 扩展中心与技能

从 **AI 能力 → 扩展中心**管理插件、MCP 与技能。旧版“技能工坊”中的技能管理已归入这里；部分内部页面仍使用“技能中心”名称。

## 三类扩展

| 页签 | 用途 |
|---|---|
| 插件 | 查看与管理扩展包，可从公开源安装或从目录导入 |
| MCP | 管理工具服务连接，可从 MCP Hub 或手动添加 |
| 技能 | 浏览、启停、创建和管理可复用操作说明，按需部署板端技能 |

点击 **添加**可看到当前环境支持的安装、导入、新建技能和 MCP 入口。受登录、服务启用与部署权限限制的操作会显示原因。

## 技能怎么用

先从技能页或技能商店查找并预览，核对适用设备、步骤和影响，再添加到当前允许的技能位置。输入区的技能搜索可帮助选择技能，也可用 `/skill <技能名> [任务]`。

技能是执行指导，实际文件、命令和设备操作仍受当前任务引擎、可用工具与授权控制。安装技能不会自动授予所有操作权限，也不保证 Moss 与 DSH 的能力完全相同。

## 本机与板端

本机技能与板端 OpenClaw 技能是不同目标。需要 OpenClaw 使用时，连接目标设备，再通过技能页面的部署或同步入口操作。电脑上的修改不会自动证明板端版本已经更新。

公网 Web Cloud 不允许直接写入服务器任意本地技能目录，需使用当前部署支持的技能商店与审核流程。

## MCP

MCP 为 Agent 提供外部工具。连接和认证状态、启停与工具权限需分别检查；安装插件或添加服务器不等于已认证成功。配置也可从 **设置 → MCP 服务**进入，自定义 MCP 是否可用以部署权限为准。
