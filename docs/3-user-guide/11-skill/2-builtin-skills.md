# 3.11.2 查看内置技能

RDK Studio 随包提供官方技能与设备知识，覆盖设备操作、板型知识、模型应用、ROS/TROS、文档检索与开发流程。实际目录随版本和知识包更新，不需要记固定数量。

## 查看与选择

在 **扩展中心 → 技能**查看技能说明、来源与状态。输入区的技能搜索可选择当前可用技能；知道名称时也可使用 `/skill <技能名> [任务]`。

| 来源 | 含义 |
|---|---|
| 随包官方技能 | 产品提供的初始知识与操作指导 |
| 用户技能 | 手动创建、安装或从经验沉淀的内容 |
| 远程技能商店 / SkillHub | 需要查找、预览并按当前部署安装的技能 |
| 板端 OpenClaw 技能 | 已部署到具体设备的技能，与本机分开管理 |

技能按需使用，不会全部自动注入每次对话。安装、启用、选中和实际加载是不同状态；需要确认执行过程时看当前任务记录，不能仅凭安装列表判断。

技能提供流程指导，不会绕过当前引擎的工具范围或权限。Moss 和 DSH 的支持可能不同。
