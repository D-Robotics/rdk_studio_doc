# 3.11.6 同步到设备

技能默认安装到 PC 端，由 Moss 加载。

如果希望板端 OpenClaw Agent 也能使用这些技能，例如板端对话、设备侧消息处理、围绕当前设备的操作，需要把技能同步到板端 OpenClaw 工作区。

## 同步流程

| 步骤 | 操作 |
|---|---|
| 1 | *技能工坊 → 已安装*（板端） |
| 2 | 选择需要同步的技能（也可勾选全部） |
| 3 | 点击 *同步技能* 按钮 |
| 4 | 等待页面显示同步完成 |

同步是从电脑端到板端。如果电脑端技能更新了，需要再次手动同步。

## 默认关闭自动同步

Studio 默认关闭"PC 安装新技能后自动同步到板端"。原因：

- 很多技能只需要在 PC 端使用，例如只分析文档或本地项目的技能
- 自动同步可能在你没注意到时占用网络和设备资源

如果团队确实需要让电脑端和板端保持一致，建议固定同步节奏，或在技能工坊中手动批量同步。

## 何时需要同步

| 场景 | 是否需要 |
|---|---|
| 板端只用作 SSH 远程目标，PC 始终在线 | 不需要，PC 端 Moss 加载技能即可 |
| 板端 Agent 需要使用某个技能 | 需要，把相关技能同步到板端 |
| 微信 / 飞书机器人部署在板端 | 需要，把消息处理相关技能同步到板端 |
| 多台设备都要使用同一技能 | 需要分别同步到对应设备 |

## 同步进度查看

同步进度会显示在技能工坊的操作状态里。失败时，先确认设备在线、OpenClaw 正常，再重新触发同步。

## 板端技能的卸载

在 *技能工坊 → 已安装*（板端）中选择技能，点击 *从板端卸载* 即可。板端卸载只移除板端副本，不影响电脑端同名技能。
