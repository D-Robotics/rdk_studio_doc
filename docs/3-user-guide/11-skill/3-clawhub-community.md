# 3.11.3 查找技能

技能市场 / SkillHub 是可复用技能的在线入口。RDK Studio 在技能工坊中提供搜索、预览、添加到本机 Moss、部署到设备 OpenClaw 和批量操作。

![技能市场：搜索、分类、预览、添加到本机、部署到设备](http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/rdk_studio/zh/skill-marketplace.png)

## 两个安装目标

| 操作 | 写入位置 | 适用场景 |
|---|---|---|
| 添加到本机 | 当前电脑的 Moss 技能目录 | 没连设备、非 RDK 主机、只希望 Moss 使用 |
| 部署到设备 | 当前 RDK 设备的 OpenClaw 工作区 | 希望板端 Agent 也能调用该技能 |

列表中会显示“已添加”和“已部署”状态。非 RDK 主机会提示“当前设备不提供 OpenClaw 部署”，但本机技能仍可使用。

## 搜索与预览

可以按关键词、分类、安装状态搜索。预览区会显示技能说明、目标和风险信息。部署前请重点看：

- 这个技能会不会执行设备命令、写文件或启动后台服务。
- 是否真的依赖 RDK 硬件。
- 风险提示是否与你准备做的事情一致。
- 关键词是否覆盖你的常用说法。

## 批量操作

技能市场支持批量添加到本机或批量部署到设备。批量部署时，如果有某一项失败，页面会给出错误提示。

## 从链接生成技能

对于 GitHub、NodeHub 或普通网页，可以使用“从链接生成技能”。Moss 会先生成草稿并停下，你确认内容后，再选择添加到本机或部署到设备。

不要让 Moss 在未确认草稿时直接写入设备；这会破坏技能工坊的安全边界。
