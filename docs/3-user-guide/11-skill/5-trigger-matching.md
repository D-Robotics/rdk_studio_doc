# 3.11.5 选择与触发技能

技能的名称、描述和触发信息帮助 Agent 判断何时使用。当前引擎、技能是否启用、任务上下文与工具支持都会影响实际使用，不能把触发词当作必定加载的承诺。

## 明确使用一个技能

1. 在 **扩展中心 → 技能**确认技能存在并查看说明。
2. 从输入区技能搜索选择，或手动输入：

```text
/skill rdk-app-development 做一个设备状态网页
```

3. 补充目标设备、工作目录和验收要求。
4. 查看回复与已有执行记录，确认 Agent 实际使用了相关流程。

## 编写触发信息

给自定义技能写清具体场景、设备类型、常见问题和特征错误。可补充常用中文、英文和缩写，但避免仅写“开发”或“设备”等过宽的词。

若没有选中预期技能，先检查技能状态和当前引擎支持，再改进描述或显式选择。技能被加载也不代表动作已执行，仍需核对工具结果。
