# 3.11.4 创建技能

从 **扩展中心 → 添加 → 新建技能**进入创建流程。也可在技能视图使用当前提供的创建或链接生成入口。

## 创建步骤

1. 说明技能适用场景、目标设备和预期结果。
2. 填写技能名称与 `SKILL.md` 内容，或让 Agent 先起草。
3. 检查步骤、命令、依赖、风险和验证方法。
4. 按当前部署允许的方式保存或安装。
5. 用小范围任务验证，再考虑部署到板端。

技能说明应写清何时使用、需要什么输入、如何判断完成、失败后怎么办。AI 草稿或外部来源内容需要你核对，尤其是删除、安装依赖、设备写入和服务操作。

## 从链接整理

技能视图提供链接生成入口时，可提交 GitHub、案例或文档链接，并说明希望学会的操作。网页访问限制、动态内容或缺失依赖都可能影响草稿，需要对照原资料检查。

链接转成草稿不等于已经安装、运行或验证。保存本机技能和部署 OpenClaw 是不同动作，使用前确认目标。

公网 Web Cloud 的创建与安装受权限限制，不能直接写入服务器任意目录。按页面支持的商店或审核流程处理。
