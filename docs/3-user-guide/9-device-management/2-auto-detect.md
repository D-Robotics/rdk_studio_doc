# 3.9.2 自动识别设备

第一次接入设备时，Studio 会自动识别设备的硬件与系统信息，并把结果保存下来。这样 Moss 回答问题时能知道自己正在面对哪一类设备。

## 会识别哪些信息

| 信息 | 用途 |
|---|---|
| 板型（X3 / X5 / S100） | 判断可以使用哪些板型能力 |
| 系统镜像信息 | 帮助 Moss 判断系统环境 |
| ROS / TROS 环境 | 给出更准确的 ROS 操作建议 |
| OpenClaw 状态 | 判断是否可以使用板端 Agent |
| BPU 类型 | 提醒模型文件是否适配当前板型 |
| 网络地址 | 在设备列表和工作台里快速查看 |

识别在添加设备时自动完成，通常不需要手动触发。如果设备重新刷了系统，可以按设备详情页的提示更新信息。

## 对 Moss 有什么帮助

Moss 会参考这些设备信息给出更贴近现场的建议，而不是只给通用答案。

例子：

| 你这样问 | Moss 会怎样处理 |
|---|---|
| “看看 BPU 占用” | 根据板型选择合适的检查方式 |
| “装一个 ROS 2 包” | 根据设备上的 ROS 环境给出命令建议 |
| “为什么 hbm 加载失败” | 根据 BPU 类型提醒模型文件是否匹配 |

这种“知道当前设备”的体验，是 Studio 与普通聊天工具最大的区别之一。

## 识别不完整怎么办

某些定制镜像可能缺少标准信息。出现这种情况时：

- Studio 会把缺失项标记为“未知”，不影响其他信息。
- 可以在设备详情页手动设置板型与镜像版本。
- 手动设置后，Moss 仍可以参考这些信息回答问题。

如果手动设置后 Moss 仍然回复不准确，建议在 [RDK 开发者社区](https://developer.d-robotics.cc) 反馈。
