# 3.9.1 切换当前设备

## 设备列表展示项

每台设备在列表中显示以下信息：

| 字段 | 说明 |
|---|---|
| 备注名 | 你给设备起的名称 |
| IP 地址 | 当前接入使用的 IP |
| 在线状态 | 当前是否能连接设备，详见 [查看在线状态](./3-online-monitoring.md) |

列表支持按名称、IP、状态排序，方便在多设备场景下快速定位。

## 三种切换激活设备的方式

| 方式 | 路径 | 适用场景 |
|---|---|---|
| 顶栏左上角设备下拉框 | 多数页面可切换 | 最快，日常使用首选 |
| 设备列表中的 *激活* 按钮 | *配置中心 → 设备连接* | 需要先看详情再决定切换的场景 |
| AI Dock 自然语言 | 直接说"切到 RDK-X5-工位2" | 编辑文档或代码时不愿离开当前位置的场景 |

切换后，当前工作区会按新设备更新。

## 切换后会发生什么

切换激活设备后，工作台、文件、代码编辑器、远程桌面和 AI Dock 会围绕新设备工作。已经打开的终端标签和对话历史不会被删除，下次切回原设备时仍可继续查看。

| 区域 | 变化 |
|---|---|
| 工作台 | 重新加载新设备状态 |
| 文件和代码编辑器 | 指向新设备的文件环境 |
| AI Dock | 使用新设备的信息 |
| 顶栏 IP 列表 | 更新为新设备的地址 |

## 顶栏 IP 速查

切换设备后，点击顶栏的设备名可以查看并复制该设备的 IP。外部工具需要 IP 时，不用再进终端查询。
