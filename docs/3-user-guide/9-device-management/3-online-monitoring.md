# 3.9.3 查看在线状态

Studio 会自动检查已添加设备是否在线。你不需要手动刷新，设备列表上的状态会持续更新。

## 状态如何变化

| 页面表现 | 含义 |
|---|---|
| 在线 | 可以使用终端、文件、Moss 等设备能力 |
| 离线 | 可能是设备断电、网络不可达或 SSH 无法连接 |
| 恢复在线 | 网络恢复后，设备列表会自动更新 |

## 在线但操作无响应的处理

有时设备显示在线，但终端或文件操作仍然卡住。可以先这样处理：

- 等几秒，看操作是否恢复。
- 检查设备是否负载过高，或是否正在运行占资源的任务。
- 如果终端还能输入，可以让 Moss 帮你查看系统状态。

如果终端也无响应，先确认电源和网络，再考虑重启设备。

## 同一设备同时操作太多

同一台设备上同时打开太多终端、文件传输和 Moss 任务时，后发起的操作可能会短暂排队。先等前面的任务结束，再看是否需要重试。

## 多人协作时的注意

如果一台设备被多人通过 Studio 同时操作，可能出现：

- 一个人的命令影响另一个人的工作。
- 设备列表里的登录信息被某人改了，其他人的 Studio 失去访问。

建议团队约定：

- 生产设备指定专人值守，避免互相影响。
- 关键设备使用个人账号或团队约定的登录方式。
- 在设备备注中标注“专人值守 / 共享调试”，让团队清楚使用规则。
