# 3.5.1 打开代码编辑器

第一次打开代码编辑器页时，Studio 会检查板端是否已经准备好编辑环境。如果还没有准备好，页面会引导你自动安装。整个过程按提示确认即可。

## 自动安装流程

1. Studio 检查当前设备是否已具备代码编辑环境。
2. 如果未安装，页面会弹出确认提示。
3. 点击 **继续** 后，Studio 会自动下载并安装所需组件。
4. 安装完成后，代码编辑器会在页面中打开。

首次安装需要等待一段时间，具体取决于板端网络、镜像环境和磁盘状态。安装完成后，再次打开代码编辑器页会快很多。

## 什么时候需要重新安装

通常不需要手动重装。只有在以下情况中，才建议按页面提示重新安装：

- 板端系统被重刷。
- 代码编辑器启动失败，页面提示组件损坏或缺失。
- 团队镜像中没有预装编辑环境。

## 启动后怎么判断成功

成功后，页面会出现类似 VS Code 的编辑界面，可以看到板端目录、打开文件，并使用内置终端。如果页面长时间空白或反复提示安装失败，请把页面错误信息复制给 Moss 排查。
