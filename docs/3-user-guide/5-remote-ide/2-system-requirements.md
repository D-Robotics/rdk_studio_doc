# 3.5.2 准备编辑环境

代码编辑器需要在板端准备编辑环境，因此对板端的内存、磁盘和网络有基础要求。打开前可以先确认下面这些条件。

## 使用前确认

| 项 | 建议 |
|---|---|
| 设备状态 | 已通过 SSH 或 Type-C 接入，且显示在线 |
| 存储空间 | 保留足够空间给代码编辑器环境和项目文件 |
| 网络 | 首次打开时，设备需要能访问安装所需资源 |
| 系统环境 | 优先使用 RDK 官方镜像或团队已验证镜像 |

## 不支持的环境

| 环境 | 原因 |
|---|---|
| 精简系统镜像 | 可能缺少自动安装所需组件 |
| 团队深度裁剪过的系统 | 可能需要先补齐运行环境 |
| 非 RDK 主机 | 可尝试使用，但能力以页面提示为准 |

如果板端是上述非标准环境，建议优先使用 RDK 官方镜像，或让熟悉系统环境的同事手动处理。

## 扩展兼容性

大多数常见扩展可以使用，但少数扩展依赖特定系统环境，可能在板端无法安装。如果扩展安装失败，先换同类扩展，或只使用基础编辑、终端和调试能力。
