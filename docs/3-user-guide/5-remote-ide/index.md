# 3.5 代码编辑器

![代码编辑器页面：连接 RDK X5 后在 Studio 内编辑板端文件](http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/rdk_studio/zh/remote-ide.png)

连接设备后，代码编辑器会在主区域打开板端项目。桌面客户端还可以把编辑器独立成悬浮窗口，方便一边看文档或 Moss，一边改代码。

代码编辑器适合做完整项目开发。代码文件仍然在板端，RDK Studio 只是把编辑体验带到桌面里，你不需要先把项目拷贝到电脑再编辑。

## 第一次使用顺序

| 顺序 | 你要做什么 |
|---|---|
| 1 | 先添加设备，并确认设备在线 |
| 2 | 打开 **代码编辑器** 页 |
| 3 | 如果页面提示准备编辑环境，按提示确认 |
| 4 | 等编辑器打开后，选择板端项目目录 |
| 5 | 需要多屏开发时，再把编辑器弹出为独立窗口 |

## 与文件的区别

| 使用场景 | 推荐 |
|---|---|
| 修改一两个文件、快速查看代码 | [3.4 文件](../4-file-manager/index.md) |
| 项目级开发、多文件、Git、调试 | 代码编辑器 |
| 跑命令、看长输出 | [3.3 终端](../3-remote-terminal/index.md) 或代码编辑器内终端 |

简单说：文件面向"快速改一改"，代码编辑器面向"开发整个项目"。

## 首次打开

第一次打开代码编辑器时，Studio 会检查设备环境，并按页面提示完成准备。设备在线、网络稳定、磁盘空间足够时体验最好。

桌面客户端支持把代码编辑器独立成悬浮窗口。需要一边看 Moss 或文档、一边改代码时，可以使用这个模式。
