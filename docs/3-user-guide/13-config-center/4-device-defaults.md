# 3.13.4 设置设备连接

设备连接区域用于设置全局的设备接入习惯。这些设置会影响已添加设备的连接体验，但不会改动某一台设备自己的 Host / IP、用户名或密码。

## 主要设置项

大多数情况下保持默认即可。只有遇到明确问题，或团队有统一要求时，再调整这些设置。

| 设置项 | 什么时候关注 |
|---|---|
| 自动重连 | 设备偶尔离线后，希望恢复网络时自动回到在线 |
| 连接超时 | 网络较慢或设备启动较慢时，连接经常还没完成就失败 |
| 同设备 SSH 并发上限 | 同一台设备上同时打开很多终端、文件任务或 Moss 任务 |
| 局域网协作 | 团队需要在同一局域网内做多设备协作测试 |
| 在线检查频率 | 设备数量较多，或希望更快看到设备上下线变化 |

## 自动重连

建议保持开启。这样设备短暂断网或重启后，Studio 会尝试恢复连接。只有明确知道某些设备会长期离线、并且不希望看到重连提示时，才考虑关闭。

## 连接超时

连接超时是 Studio 等待 SSH 响应的时间。设备刚启动、网络较慢或跨网络访问时，可以适当调长；本地网络很稳定时，通常不需要改。

## 同设备 SSH 并发上限

同一台设备上同时打开太多终端、文件传输和 Moss 任务时，新任务可能会排队。一般不需要调整；只有确认设备性能和网络都足够时，再考虑提高。

## 局域网协作

个人日常开发保持关闭即可。只有团队内需要做多电脑、多设备协作测试时，再按团队约定开启。

## 在线检查频率

设备较少时，保持默认即可。设备很多、网络压力较大时，可以适当降低检查频率；需要更快看到上下线变化时，再适当提高。
