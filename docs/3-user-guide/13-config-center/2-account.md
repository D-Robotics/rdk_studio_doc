# 3.13.2 登录账号

账户与安全区域显示当前登录的 D-Robotics 账户信息，并提供退出登录、本地会话清理等操作。

## 已登录信息

登录成功后，账户区域显示：

- 用户名 / 邮箱
- 用户角色（如有 RBAC 设置）
- 登录时间与会话剩余有效期
- 关联的组织 / 团队（如适用）

## 退出登录

| 操作 | 行为 |
|---|---|
| 退出登录 | 清除本机会话 token，保留其他配置（设备列表、模型条目、技能等） |
| 退出登录并清理本地数据 | 同时清除设备列表、模型条目、历史对话等本机数据 |

退出后下次启动 Studio 需要重新登录。如果只是临时退出，使用 *退出登录*；如果是把电脑借给他人，使用 *退出登录并清理本地数据*。

## 登录状态异常

如果遇到“显示已登录但操作受限”、登录页反复跳转等情况，优先按这个顺序处理：

1. 在账户区域点击 **退出登录**，重新登录。
2. 重启 RDK Studio 后再试一次。
3. 仍然异常时，使用页面提供的本地会话清理入口，再重新登录。

一般不需要手动查找或修改本地会话文件。会话数据只用于保持登录状态，不会保存你的账号密码。

## 账户切换

如果需要切换到另一个 D-Robotics 账户：

1. 退出登录
2. 重启 Studio（部分场景需要重启才能清理浏览器 cookie 缓存）
3. 用新账户登录

切换账户后，Studio 会从云端同步该账户对应的配置（如有云端同步开关启用）。本机的设备列表、技能等不会被覆盖——这些是本机数据，不随账户切换。

## 多账户共用一台机器

不同 D-Robotics 账户可以在同一台 PC 上共用 Studio，但同一时间只能登录一个账户。建议：

- 团队场景：每个人在自己的 PC 上独立登录
- 共享 PC：每次切换账户前先退出登录并清理本地数据，避免数据混淆

如果企业统一登录页面无法打开，或登录后仍显示无权限，请联系企业内 IT 或管理员确认账号状态。
