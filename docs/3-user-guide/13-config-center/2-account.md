# 3.13.2 登录账号

在 **设置 → 账户与安全** 查看当前登录状态，按页面提示登录、退出或处理账号问题。模型请求使用当前账号可用的权限与额度。

## 桌面账号与本机数据

桌面端已保存的项目、聊天、标题、置顶、归档和草稿属于当前本机数据目录。退出登录或切换账号后，这些记录仍可查看。账号切换不是隐藏本机历史或清除文件的方式。

共享电脑时，应使用独立的系统用户或数据目录隔离本机工作记录。删除本机历史会影响同一数据目录的使用者；删除项目不会删除项目文件。

## DSH 历史

保存的 DSH 内容可在本机历史中查看；恢复执行以官方会话为准。跨账号继续会创建当前账号的关联任务，原账号的任务与审批不会由新账号接管。

**从本机历史删除**和**永久删除 DSH 对话**是两种操作，后一种只对当前账号有权删除的官方对话提供。详见 [历史会话](../2-ai-chat/3-multi-session.md)。

## 网页版

Web 部署的项目、对话和任务按账号隔离。退出后登录另一个账号，应使用该账号自己的数据与权限，不能套用桌面本机历史规则。

## 登录异常

先确认网络和页面错误提示，再退出重登；必要时重启客户端。若历史处于只读恢复状态，应修复存储或服务并重试恢复，避免把数据重置当作登录修复。
