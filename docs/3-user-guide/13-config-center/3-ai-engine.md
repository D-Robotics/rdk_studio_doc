# 3.13.3 配置 AI 模型

打开 **设置 → AI 模型与服务**。这里把运行引擎、模型服务和操作确认设置放在一起，但它们各自生效。

## 运行引擎

**Moss**是内置引擎，**DSH**需要检测就绪后才能选择。点击 **重新检测运行引擎** 查看检测结果与原因。

修改默认引擎只影响之后新建的任务；已有任务继续使用原引擎。输入区显示当前任务引擎或新任务默认引擎，点击可回到设置。DSH 不可用时不会自动改用 Moss。

## 当前模型

模型配置主要用于 Moss。可以选已保存模型，新增并启用一条模型配置，或编辑、测试和删除当前条目。

| 字段 | 填写方式 |
|---|---|
| 显示名称 | 自己能识别的名称 |
| 服务商 | 按实际服务商选择；兼容服务按兼容接口配置 |
| 模型 ID / 名称 | 使用服务商给出的完整值 |
| API Key | 在设置中填写；已保存密钥按页面提示保留或替换 |
| Base URL | 服务商或团队提供的接口地址 |

测试厂商 API 后点击 **保存**或**新增并启用**。保存失败时查看错误，原配置不会因为输入了新字段就代表已更新。

可用时也能从输入区模型选择器切换模型。只有一个默认 Moss 别名时，重复选择器可能隐藏。Moss 模型配置不会将 DSH 任务改绑为 Moss，也不等于 DSH 的模型设置。

## 内置与本机模型

当前部署有可用内置预设时，可以重新应用它；缺 Key 或缺预设时按提示配置。**仅保留内置预设**会删除本地多余模型条目，使用前确认需要保留的配置。

本机 Ollama 在 [本地大模型](../12-local-models/index.md) 页安装和下载。点击 **设为主模型配置**前确认模型支持工具调用。板端 OpenClaw 需要板端可访问的模型地址。

## MCP 与历史 Agent 诊断

自定义工具连接在 **MCP 服务**管理，受部署和权限限制。历史 Agent 诊断只说明兼容会话的安装或调用问题，不能据此认为外部编码 Agent 当前可在工作台选择。

备份与导入见 [模型配置导入导出](./5-import-export.md)。
