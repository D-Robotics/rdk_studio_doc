# 3.13 配置中心

从左侧底部 **设置** 打开配置中心。当前设置按用途分区，入口可能随部署形态隐藏。

| 区域 | 内容 |
|---|---|
| 账户与安全 | 登录状态、账号与安全操作 |
| 界面显示 | 主题、语言和对话显示偏好 |
| 设备连接 | SSH 与设备连接相关选项 |
| 数据与存储 | 本机数据位置、空间与目录设置，公网 Web Cloud 不显示此区 |
| AI 模型与服务 | 新任务运行引擎、模型配置、连通性测试与操作确认策略 |
| MCP 服务 | 配置和管理允许使用的 MCP 连接 |
| 飞书消息接入 / 微信消息接入 | 消息渠道配置，公网 Web Cloud 不暴露这些进程级配置 |
| 应用与更新 | 版本、更新、CLI 与诊断维护入口 |

本机 Ollama 的安装、下载和模型文件管理位于独立的 [本地大模型](../12-local-models/index.md)页面。

模型服务、任务引擎和工作方式是不同设置。修改运行引擎默认值只对新建任务生效；已有任务保持原引擎。
