# 3.13 配置中心

配置中心位于左侧导航底部。大多数设置保持默认即可；只有遇到连接、模型、消息渠道或账号问题时，再进入这里调整。

![配置中心：左侧显示设置分类，右侧显示当前设置页](http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/rdk_studio/zh/settings-panel.png)

## 使用顺序

| 顺序 | 你要做什么 |
|---|---|
| 1 | 先确认当前账号是否正确 |
| 2 | 设备连不上时，再看 **设备连接** |
| 3 | Moss 或模型异常时，再看 **AI 引擎** |
| 4 | 要接入飞书、微信时，再配置消息渠道 |
| 5 | 换电脑或团队需要共享配置时，再使用导入导出 |

## 设置结构

| 区域 | 主要内容 |
|---|---|
| 账户与安全 | 当前账号、退出登录、本地会话与数据清理 |
| 设备连接 | SSH 默认值、设备连接、网络与重连相关选项 |
| 界面显示 | 显示密度、字体/缩放、桌面端快捷窗等体验项 |
| AI 引擎 | 思考/快速模型、服务商、API Key、Base URL、连通性测试 |
| 消息渠道 · 飞书 | 飞书机器人凭据、通道启停、配对用户 |
| 消息渠道 · 微信 | 微信扫码绑定、账号列表、通道重启 |
| 应用与更新 | 更新、命令行工具、诊断包与维护入口 |

本地 Ollama 的安装、下载和模型文件已经独立到 [3.12 本地大模型](../12-local-models/index.md)。

设置里的 AI 引擎只负责管理 Moss 的快速/思考模型配置。

不确定某项设置含义时，先保持默认。遇到问题时，可以把页面提示或脱敏后的截图发给 Moss 排查。
