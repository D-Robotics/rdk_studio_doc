# 3.13.5 导入导出配置

**设置 → AI 模型与服务**底部的 **导出 / 导入**用于备份和恢复模型配置。它不是全应用备份，不包含设备列表、SSH 凭据、消息渠道、历史对话或项目代码。

## 导出

1. 至少保存一条模型配置。
2. 在模型配置底部点击 **导出**。
3. 保存生成的 `rdkstudio-moss-config-<时间戳>.json`。

桌面或本地环境导出可能包含 API Key 等密钥；公网 Web Cloud 的导出范围受限。当前界面没有通用“全部配置/仅设备”导出，也不能假定存在“脱敏”勾选项。分享前自行核对并移除敏感内容。

## 导入

在同一位置点击 **导入**，选择包含模型条目的 JSON 文件。导入成功后检查模型列表、当前选择、密钥状态和 API 连通性，再使用工作台。

文件格式错误、没有模型条目或导入失败时，按提示修复或重新创建配置。不要假定界面提供逐项冲突合并或整个应用配置恢复。

## 其他数据

项目文件、对话历史和本机数据目录需要另外备份。改变数据目录不会自动搬迁旧文件；历史恢复问题优先使用专门的重试恢复入口。
