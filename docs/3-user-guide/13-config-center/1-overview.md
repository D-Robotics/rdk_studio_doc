# 3.13.1 看懂设置页

## 设置区域

| 区域 | 主要内容 | 生效时机 |
|---|---|---|
| 账户与安全 | 登录账户、退出登录、本地数据清理 | 立即生效 |
| 设备连接 | SSH、设备在线检查、自动重连、局域网协作 | 大多立即生效 |
| 界面显示 | 显示密度、缩放、桌面端体验 | 立即生效 |
| AI 引擎 | 模型条目、思考/快速模型、测试 | 立即生效 |
| 消息渠道 · 飞书 | 飞书应用凭据、通道启停、用户绑定 | 保存后生效，运行态操作可能重启通道 |
| 消息渠道 · 微信 | 微信扫码绑定、账号移除、通道重启 | 保存或扫码后生效 |
| 应用与更新 | 版本检查、CLI、诊断包、重置 | 部分操作需要重启 |

## 使用建议

如果不确定某个设置的作用，优先保持默认。多数设置保存后会立即生效；少数和应用更新、通道重启相关的操作，页面会提示是否需要重启。

## 跳转与联动

RDK Studio 会从多个地方跳入设置：

- AI Dock 模型横幅 → AI 引擎或本地大模型。
- OpenClaw 模型配置 → AI 引擎中的思考模型。
- 左侧设置按钮 → 默认打开设置页，并记住上次区域。
- 应用与更新 → CLI 和诊断包相关操作。

## 重置 Studio

重置会清理本机设备、模型配置、历史对话和部分缓存。它是不可逆操作，建议先导出配置。若只是退出当前账号，请优先使用 *账户与安全 → 退出登录*。
