# 3.13.1 看懂设置页

设置分区用于解决不同问题：模型连不上看 **AI 模型与服务**，设备连接失败看 **设备连接**，本机数据位置看 **数据与存储**。

## 哪些设置影响当前任务

| 变化 | 影响 |
|---|---|
| 新任务默认运行引擎 | 只影响之后新建的任务，已有任务不改绑 |
| 模型条目 | 保存和切换后按当前模型配置使用；不改变任务引擎 |
| 项目或设备目录 | 改变工作位置，继续历史时需核对原任务绑定 |
| 数据存储目录 | 原文件不会自动迁移，部分设置需重启 |
| 应用更新 | 按更新提示保存文件并重启 |

输入区的引擎标识会跳转到运行引擎设置，模型配置入口会跳转到 AI 模型与服务。当前模型只有一个默认别名时，输入区可能不显示重复的模型控件。

## 部署差异

公网 Web Cloud 按账号隔离用户数据，不显示数据与存储、飞书和微信的进程级配置；自定义 MCP 和宿主能力也受部署权限限制。

## 数据恢复与重置

模型配置导出不包含完整本机数据。历史恢复失败时先恢复本机存储和服务，再使用 **重试本机历史恢复**。应用重置或删除数据可能影响同一本机数据目录中的其他账号，不能用来代替退出登录。
