# 3.6.1 打开远程桌面

## 自动启动流程

第一次打开 *远程桌面* 页，Studio 会执行以下步骤：

1. 检查当前设备是否具备远程桌面环境。
2. 如果缺少组件，页面会提示你确认安装。
3. 安装完成后，Studio 会自动启动远程桌面。
4. 页面出现板端桌面画面后即可操作。

整个过程不需要你手动登录板端安装。首次准备需要等待一段时间，之后再次打开会快很多。

## 密码认证

为了避免别人随意打开你的板端桌面，首次启动时可能会要求设置远程桌面密码：

- 第一次启动时页面会显示默认 8 位口令，也可以改成设备上实际使用的口令。
- 这个口令只用于打开远程桌面，不是设备的 SSH 密码。
- 如果换电脑、换设备或手动改过板端口令，请在页面里重新填写后再连接。

## 安全注意

不要把板端远程桌面服务直接暴露到公网。正常使用 RDK Studio 打开远程桌面即可。

如果页面打不开、黑屏或连接断开，优先把页面提示和设备状态复制给 Moss，让它帮你检查网络、桌面组件和权限问题。
