# 3.15.2 查看 Token 用量

Token 是模型处理文本时使用的计量单位。消息、附件和工具往返越多，通常消耗越高。

## 怎样看用量

查看当前任务或对话中提供的用量信息。Moss 与 DSH、不同模型服务商提供的字段可能不同；缺失数据不能按零处理。

| 信息 | 用途 |
|---|---|
| 输入 / 输出 Token | 比较一次任务处理的文本量 |
| 累计用量 | 观察当前页面标明范围内的消耗 |
| 耗时 / 操作次数 | 辅助判断任务是否反复重试 |
| 费用估算 | 仅供粗略比较，不能代替账单 |

会话、单次运行、账号额度和模型平台账单是不同统计范围。切换会话或引擎后，先确认显示范围，不要直接跨范围相加。

## 减少无效消耗

说明清晰目标，日志只提供相关片段；不要重复启动同一个任务。无关目标另开对话，复杂需求先用计划或 Spec 对齐。

选择模型时兼顾能力和成本。本机模型也需要足够的工具调用能力。正式计费、缓存折扣和账号额度以对应平台为准。
