# 3.15 监控与运维

运行总览用于查看当前任务、后台运行、后台进程和定时任务；具体内容由当前引擎与部署提供。

- 先看任务是执行中、等待、待确认、已停止还是恢复待处理。
- 打开对应任务查看结果与错误；需要停止时使用它的停止入口。
- 服务进程、Agent 运行和定时任务分别管理，不能把其中一个停止当成全部结束。
- Token 和费用显示用于辅助观察，正式额度与账单以账号或模型服务平台为准。
