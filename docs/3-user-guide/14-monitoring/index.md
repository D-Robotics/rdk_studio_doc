# 3.15 监控与运维

监控与运维主要看两件事：顶部任务队列，以及 AI Dock 的 Token 用量。一个帮助你看任务进度，一个帮助你判断 AI 任务是否异常消耗。

## 使用顺序

| 顺序 | 你要看什么 |
|---|---|
| 1 | 正在烧录、部署、传文件时，先看顶栏任务队列 |
| 2 | 点击任务芯片，回到对应页面看详细进度 |
| 3 | AI 任务变慢或费用异常时，再看 Token 用量 |
| 4 | 需要精确账单时，以模型平台账单为准 |

## 查看任务进度

顶栏右侧会集中显示烧录、OpenClaw 部署、批量文件传输、技能同步等长任务。点击任务芯片可以回到对应页面查看进度。重要任务建议等页面显示完成后再关闭窗口。

## 查看 Token 用量

AI Dock 会显示本次对话或任务大概消耗了多少模型资源。这个数字适合用来判断任务复杂度和排查异常消耗，最终计费仍以模型平台为准。
