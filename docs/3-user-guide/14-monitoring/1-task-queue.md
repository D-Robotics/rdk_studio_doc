# 3.15.1 查看任务进度

任务队列位于 RDK Studio 顶栏右侧，把当前进行中的长任务集中展示。你不需要切换页面，就能看到烧录、部署、批量传输等任务的进度。

## 顶栏会出现的任务类型

任务队列主要展示“耗时较长、切到其他页面后仍需要关注”的任务，例如：

| 类型 | 触发场景 |
|---|---|
| 烧录 | *烧录* 页启动烧录后 |
| OpenClaw 部署或卸载 | *板端 Agent* 页触发的长任务 |
| 批量文件传输 | *文件* 中上传或下载多个文件 |
| 技能批量安装或同步 | *技能工坊* 中批量操作 |
| 设备诊断 | Moss 或页面触发的诊断任务 |

## 不进入顶栏的任务

一些短操作不会进入顶栏，例如普通对话、单条 SSH 命令、设备在线状态检查等。它们的结果会在 AI Dock、终端或对应页面里显示。

如果某个任务没有出现在顶栏，不代表它没有执行。优先回到触发它的页面查看进度和结果。

## 操作

| 操作 | 怎么做 |
|---|---|
| 查看详情 | 点击芯片 → 跳转到对应功能页（如点烧录芯片跳到 *烧录* 页） |
| 取消 | 仅部分任务芯片支持取消按钮；其他任务需要去对应功能页操作 |
| 暂停 / 重试 | 不集中在顶栏，需要去对应功能页操作 |

## 关闭窗口前

重要任务建议等页面显示完成后再关闭窗口。关闭窗口后，顶栏里的进度可能无法继续展示；任务是否继续取决于具体功能。

## 任务历史

顶栏只显示当前进行中的任务。历史记录请回到对应功能页查看，例如烧录历史在 *烧录* 页，Moss 对话历史在 AI Dock 会话列表中。
