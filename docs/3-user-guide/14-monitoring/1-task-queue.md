# 3.15.1 查看任务进度

打开顶栏的运行总览，查看当前 Agent 执行、计划、后台对话、后台进程和其他长任务。不同任务提供的进度与操作可能不同。

## 观察与停止

| 对象 | 需要确认 |
|---|---|
| 当前 Agent 任务 | 执行状态、待确认内容、停止是否完成 |
| 后台任务 | 任务所属对话、引擎和恢复状态 |
| 后台进程 | 设备、本机位置、日志和停止入口 |
| 烧录等长操作 | 回到原功能页核对真实进度与结果 |

恢复待处理不等于仍在执行。点击相应条目回到任务，核对状态后继续。不要因为切换页面或关闭某个面板就认为后台任务已停止。

## 定时任务

在运行总览提供的定时任务面板中，可以查看任务提示、时间安排、下一次运行和状态。创建时核对名称、任务要求与计划；默认待审批的任务需要批准后才运行。

按页面提供的按钮批准、暂停、恢复或停止。待审批、已暂停、熔断与运行中是不同状态；报错时保留原因并修复，不要重复创建相同任务。账号只应看到和控制自己有权管理的任务，具体支持以部署为准。

重要任务关闭应用前先确认是否完成或停止。定时运行依赖相关服务继续可用，不能假定退出客户端后所有任务都会照常执行。
