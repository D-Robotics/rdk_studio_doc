# 3.8.3 保存 Wi-Fi 配置

通过 Studio 连接成功的 Wi-Fi 会保存到设备上。重启板端后，设备通常会自动重连，不需要每次重新输入密码。

## 重启后没有连上怎么办

先按下面顺序检查：

- 路由器和 Wi-Fi 是否正常。
- Wi-Fi 密码是否被修改过。
- 设备是否离路由器太远，或被金属外壳、机柜遮挡。
- 路由器是否允许新设备接入，DHCP 是否能分配 IP。

如果只是 IP 变了，这通常不是故障，而是路由器重新分配了地址。需要固定地址时，建议在路由器后台给设备绑定固定 IP。

## 删除已保存网络

不再使用的 Wi-Fi 可以在 Wi-Fi 配置弹窗的 *已保存* 列表里删除。删除后，设备会忘记这条网络和对应密码，下次连接需要重新输入。

如果页面删除失败，把页面提示发给 Moss，让它帮你判断下一步。

## 长期使用建议

长期使用的设备更建议使用有线网络和固定 IP，减少 Wi-Fi 信号波动和地址变化带来的影响。

完整的 WiFi 故障排查见 [5.7 网络连接失败](../../5-faq/7-network-failed.md)。
