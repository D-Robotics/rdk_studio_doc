# 3.8.2 添加隐藏 Wi-Fi

## 手动添加隐藏 SSID

有些企业或实验室 Wi-Fi 不会出现在扫描列表里，需要手动添加：

1. 点击 Wi-Fi 配置弹窗底部的 *手动添加 SSID*
2. 输入 SSID 名称（区分大小写）
3. 输入密码
4. 如果页面要求选择加密类型，按路由器或网络管理员提供的信息选择
5. 勾选 *隐藏网络*
6. 点击 *连接*

连接成功后，设备会保存这条网络。下次开机时，通常会自动尝试重连。

## 高级选项怎么选

大多数家用和办公网络不需要改高级选项。只有网络管理员明确要求时，再按对方提供的参数填写。

如果不确定某个选项的含义，先保持默认。连接失败后，把页面提示发给 Moss，或者请网络管理员确认网络类型和密码。

## 有线和无线同时使用

如果设备同时插了网线又连接 Wi-Fi，系统通常会优先选择更稳定的网络。日常调试不需要特别处理。

如果你只是想临时确认 Wi-Fi 是否可用，可以先拔掉网线再测试。长期固定网络策略时，建议让熟悉网络配置的同事处理。

## 2.4 GHz 与 5 GHz

如果同一个路由器同时提供 2.4 GHz 和 5 GHz，设备一般会自己选择。

遇到连接不稳定时，可以在路由器后台把两个频段改成不同名称，例如 `office_2g` 和 `office_5g`，然后在 Studio 里选择更稳定的那个。
