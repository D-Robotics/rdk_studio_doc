# 3.8.1 打开 Wi-Fi 配置

## 打开 Wi-Fi 配置

最常用的入口是顶部工具栏的 Wi-Fi 图标。点击后，会打开当前设备的 Wi-Fi 配置弹窗。

首次添加设备时，也可以跟着添加设备引导进入 Wi-Fi 步骤。平时如果要检查默认设置，可以到 *配置中心 → 设备连接*。

## 看懂连接状态

顶部 Wi-Fi 图标会显示当前设备的大致状态：

| 状态 | 含义 |
|---|---|
| 已连接 | 已连上 Wi-Fi，并显示网络名称 |
| 未连接 | 设备当前没有可用的 Wi-Fi 连接 |
| 连接中 | 正在扫描、连接或获取 IP |
| 连接失败 | 密码、信号、路由器或 DHCP 等环节可能有问题 |

Wi-Fi 配置弹窗会展示连接过程和失败提示。通常先检查三件事：密码是否正确、设备是否离路由器太远、路由器是否允许新设备接入。

## 用 Moss 排查连接问题

Wi-Fi 名称和密码建议在 Wi-Fi 配置弹窗里填写。连接失败时，可以把页面提示贴到 AI Dock，让 Moss 帮你判断下一步：

```text
这台板连接 office_2.4g 失败，日志停在 DHCP 获取 IP，帮我排查。
```

如果要排查另一台板（不是当前激活设备），先在输入区切换目标设备，或在描述里写清楚设备名称。
