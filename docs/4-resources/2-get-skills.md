# 4.2 技能获取

获取技能的入口统一在 **技能工坊**。你可以在这里查看本机 Moss 技能、设备 OpenClaw 技能、技能市场、创建技能和链接生成。

## 获取路径

| 路径 | 适合场景 |
|---|---|
| 技能市场 / SkillHub | 搜索远程技能，添加到本机或部署到当前设备 |
| 内置可部署技能 | 使用 RDK Studio 打包内置的精选技能 |
| 本机沉淀技能 | 管理对话生成、手动创建或市场写入的用户技能 |
| 从链接生成 | GitHub、NodeHub、网页、文档链接转成技能草稿 |
| 手动粘贴 | 把已有 `SKILL.md` 内容粘贴到创建页校对后写入 |

## 添加到本机还是部署到设备

| 操作 | 结果 |
|---|---|
| 添加到本机 | Moss 可用，不经过 SSH，不要求当前有 RDK 设备 |
| 部署到设备 | 写入当前 RDK 设备的 OpenClaw 工作区，板端 Agent 可用 |

非 RDK Linux 主机通常不能部署 OpenClaw 技能。遇到“设备不可部署”时，可以先添加到本机 Moss。

## 让 Moss 帮你找

可以直接在工作台问：

```text
有没有适合排查 USB 摄像头黑屏的技能？先列候选，不要安装。
```

确认候选后，再让 Moss 打开技能工坊或按链接生成草稿。部署或写入前仍要检查风险字段。
