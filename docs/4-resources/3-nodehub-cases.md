# 4.3 NodeHub 案例

NodeHub 是 D-Robotics 官方案例平台，面向完整项目、示例代码和运行说明。

技能市场 / SkillHub 面向单个 `SKILL.md`；NodeHub 面向“可以下载、运行、复现”的项目案例。

## 平台分工

| 平台 | 内容 | 与 RDK Studio 的关系 |
|---|---|---|
| NodeHub | 完整项目、README、依赖、截图、视频、可选技能 | 可以把案例链接交给 Moss 起草技能 |
| 技能市场 / SkillHub | 单个 `SKILL.md` | 在技能工坊中添加到本机或部署到设备 |
| 地瓜开发者论坛 | 问答、经验贴、问题复盘 | 左侧资源入口可直接打开 |
| RoboGo | 云端一站式机器人开发平台，覆盖数据闭环、训练场、Agent 开发服务和应用部署等流程 | 左侧资源入口可直接打开 |

## 从 NodeHub 到技能

1. 打开 NodeHub 案例详情页。
2. 复制案例 URL。
3. 在 RDK Studio 中进入 *技能工坊 → 从链接生成技能*。
4. 粘贴 URL，让 Moss 先生成 `SKILL.md` 草稿。
5. 校对命令、风险和适用板型。
6. 添加到本机 Moss，或部署到当前 RDK 设备 OpenClaw。

不要把未验证的案例直接部署成高权限技能。至少先手动跑通一次 README 中的关键命令。
