# 3.11.2 Built-in skills

RDK Studio bundles official skills and device knowledge covering operations, board models, AI applications, ROS/TROS, documentation, and development workflows. The catalog changes with releases and knowledge updates; no fixed count is required.

## Inspect and select

Open **Plugin Center → Skills** for descriptions, sources, and state. Use composer skill search to select an available skill, or type `/skill <skill-name> [task]` when you know its name.

| Source | Meaning |
|---|---|
| Bundled official skills | Initial product knowledge and operating guidance |
| User skills | Created, installed, or distilled from experience |
| Remote store / SkillHub | Skills to find, preview, and install where permitted |
| Board OpenClaw skills | Deployed to a specific device, separate from local skills |

Skills are used as needed rather than all injected into every conversation. Installed, enabled, selected, and actually loaded are different states. Inspect current task records when necessary instead of inferring use from an installation list.

Skills guide work without bypassing runtime tools or permissions. Moss and DSH support may differ.
