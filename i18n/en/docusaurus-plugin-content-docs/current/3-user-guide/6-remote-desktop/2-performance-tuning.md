# 3.6.2 Pop out remote desktop window

Desktop client splits remote viewer into detachable float:

- Main Studio retains other workspaces
- Float can pin front, fullscreen, relocate to spare monitor
- Multiple boards ⇒ multiple floats in parallel glance mode

Use *Float* in the top‑right of the Remote desktop toolbar.
