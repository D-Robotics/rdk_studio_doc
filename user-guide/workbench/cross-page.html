3.1.2 跨页面联动

工作台把 Moss 对话和“当前工作区”放在同一屏。右侧工作区围绕当前项目、设备、目录和诊断状态，展示你当前能查看和操作的内容。

现场卡片​

工作区的“现场”页主要包含以下卡片：

卡片行为
设备管理打开设备管理/添加设备入口；已连接设备时可切换或验证 SSH
项目空间设置设置或查看当前远端项目目录；有 Git 仓库时显示变更摘要
把当前信息交给 Moss把项目、设备、目录和变更摘要引用到输入框
诊断快照采集设备运行时状态，并可一键送入 Moss
历史对话打开历史会话，继续之前的任务

现场页底部还有快捷入口：历史、终端、文件。它们会在右侧工作区内切换面板，不需要离开当前工作台。

工作区面板​

工作区顶部可以切换这些面板：

面板当前作用
现场查看设备、项目目录、Git 状态、诊断快照与历史入口
终端在当前项目目录下打开 SSH 终端
文件浏览、上传、下载、编辑当前目录下的远端文件
变更查看远端项目 Git 状态，必要时初始化仓库
历史打开本地会话历史
浏览器当 Moss 打开网页或预览时出现，可刷新、复制 URL 或关闭

终端、文件和变更都围绕同一个“当前项目目录”工作。没有设置目录时，界面会先引导选择板端目录或远端目录。

外部页面联动​

左侧主导航中的 烧录、远程桌面、代码编辑器、板端 Agent、本地大模型、技能工坊 仍是独立页面。Moss 或工作区面板可以带你打开这些页面，例如：

  • 需要刷系统时打开 烧录。
  • 需要图形桌面时打开 远程桌面。
  • 需要项目级开发时打开 代码编辑器。
  • 需要部署或修复 OpenClaw 时打开 板端 Agent。
  • 需要本机 Ollama 时打开 本地大模型。

离线与只读状态​

工作区顶部会显示当前设备、目录和可执行状态：

状态含义
SSH 已验证 / 可执行终端、文件、变更和 Moss 设备操作可使用
离线快照 / 只读可以查看已有信息和历史，但设备操作会等待重连
未设置板端目录终端、文件、变更会先引导选择目录
未选择设备Moss 可做方案和知识回答，设备执行需要先添加设备
