3.13.3 配置 AI 模型

AI 引擎用于告诉 Moss：复杂任务用哪个模型，快速回答用哪个模型。通常先理解 思考模式 和 快速模式 两种默认模型配置即可。

思考模式与快速模式​

模式用途推荐选择
思考主对话、复杂任务、设备排障、代码修改能力更强的云端模型或团队模型
快速简短问答、摘要、文件浏览总结成本较低的模型或本机 Ollama

如果快速模式使用本机 Ollama，但本机模型没有启动，AI Dock 输入区会提示你跳转到 本地大模型。

页面字段怎么填​

页面字段填什么
显示名称你自己好识别的名字，例如“公司模型”或“本机快速模型”
服务商选择模型平台或团队自建服务对应的服务商
模型名称按模型平台给出的名称填写，大小写要一致
API Key（访问密钥）外部模型通常需要填写；本机 Ollama 通常不用填。请在页面里填写，不要直接发到对话中
Base URL（服务地址）团队有自建模型服务时填写；使用平台默认地址时可留空

保存后，可以在“思考”和“快速”之间分别选择不同模型。

服务商选错怎么办​

服务商要和模型平台一致。比如同样是“兼容 OpenAI 接口”的服务，就选对应的兼容类型；如果是本机 Ollama，就选 Ollama。选错时常见表现是测试失败、模型不存在或密钥无效。

如果不确定选哪个，可以把模型平台文档或团队给你的字段说明发给 Moss，让它帮你判断。涉及 API Key 的截图请先遮住密钥内容。

与本地大模型的关系​

本地大模型页负责安装、启动、下载和测试 Ollama 模型；AI 引擎负责把这个模型分配给 Moss。推荐流程是先在本地大模型页点击“设为快速模型配置”，再回到 AI 引擎确认。

与 OpenClaw 的关系​

板端 Agent 可以跟随 Moss 的思考模型，但有些模型不能直接给板端使用。本机 Ollama 默认只在电脑上运行，板端通常访问不到；这类情况界面会给出提示。

测试连通性​

保存前建议点击测试。测试失败时优先检查：

  • 服务商是否选对。
  • 模型名称是否和平台给出的名称一致。
  • API Key 是否复制完整，前后有没有多余空格。
  • Base URL 是否填写了团队要求的完整地址。
  • 本地 Ollama 是否已经启动，并且模型已经下载完成。
