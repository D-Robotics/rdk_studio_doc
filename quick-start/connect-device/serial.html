2.3.3 串口日志

串口入口用于查看电脑连接到设备后的启动日志，适合系统启动失败、网络不可达、需要确认启动过程的情况。

串口不会把设备加入设备列表，也不会让文件、Moss 设备操作或 OpenClaw 自动可用。

串口能做什么​

能力支持情况
查看启动日志和系统输出支持
救援网络不可达的设备支持
进入命令行手工修复配置取决于设备是否开放串口登录
保存为 RDK Studio 设备不支持
文件、远程桌面、代码编辑器不支持，需要 SSH
Moss 设备操作不支持，需要 SSH

如果页面没有显示串口入口，请以界面提示为准。

操作步骤​

  1. 将调试线连接到 RDK 调试口或 USB-UART 模块。
  2. 确认电脑已经识别到这条串口线。
  3. 打开 添加设备 → 本机串口日志，或进入 终端 页使用本机串口栏。
  4. 点击 添加，在系统弹窗中授权对应串口。
  5. 选择波特率后点击 连接。

RDK 调试口常用 115200。如果看到乱码，请按板型资料尝试其他波特率。

常见问题​

现象处理
下拉为空先点击 添加，在系统弹窗中授权对应串口
系统能看到串口，但 RDK Studio 看不到刷新串口列表；确认选择的是调试线对应的端口
授权列表里都是未知串口点击 清除未知串口 后重新添加
打开失败串口可能被其他终端工具占用，关闭后再试
输出乱码切换波特率；确认 RX/TX/GND 接线正确

后续操作​

串口只能帮助你恢复到“设备能启动、能联网或能 SSH”的状态。恢复后请回到 2.3.2 SSH 添加设备，把设备正式加入 RDK Studio。
